# builder1 基本仕様・検証項目

## 実装範囲

`SuperRailBuilderX_builder1` は、始点と終点の2点からKaizPatchXの自動分割設定を持つレールを生成する最初のツールです。

- 右クリックで始点、終点の順に選択する。
- 左クリックで最後の選択を1段階取り消す。
- Cで選択を全解除する。スナップ設定は維持する。
- レールアイテムを手に持ってEnterを押すと、そのRailPropertyを複製し、`autoSplit=true` として生成する。
- Pで位置・角度スナップを切り替える。初期値はOFF。
- Ctrl+Pで角度を1度、5度、15度の順に切り替える。初期値は5度。
- Ctrl+Zでbuilder1が直前に生成した論理レールを1回だけ撤去し、生成前の選択状態へ戻す。
- Hで操作説明、Qでツールを終了する。

## 座標と方向

- スナップOFFでは空間点を0.001ブロック単位へ丸める。
- スナップONでは空間点を0.5ブロック単位へ丸め、自由点同士のアンカー角を現在の角度刻みへ丸める。
- 自由点同士は、始点から終点へ向くアンカーと、その反対を向く終点アンカーを作る。`direction` はアンカー角に最も近い8方向を設定する。
- 位置の0.5ブロック格子と角度スナップを同時に満たせない場合、位置は格子を維持し、角度はアンカーへ適用する。この場合は完全な直線からわずかに曲がる可能性があり、SRB3の仕様を参照できた段階で再検討する。

## 既設レール端部との接続

- 空間点同士は生成できる。
- 既設端部と空間点の組み合わせは選択・プレビューだけ行い、生成は未実装として拒否する。
- 既設端部同士は生成できる。既存コアを上書きしないよう、各端部の `getNeighborPos()` 側に反転したRailPositionを作成する。
- 新しいRailPositionは精密座標を既設端部と一致させ、`direction` とアンカー角を180度反転し、アンカー勾配の符号も反転する。
- 両アンカーの水平長は、選択した端部間距離の2/3に設定する。

## 破壊的な生成

builder1はクリエイティブ敷設に近い試験方針として、生成経路上のブロックを道床へ強制置換します。他レールの道床・コアを含む既存ブロックを保護しません。

- 複数セクションでは `RailChunkSectioner.split` の各RailMapSectionを直接敷設し、セクションコアを生成する。
- 短いレールなど分割結果が1セクションの場合は、KaizPatchX標準と同様に通常コア1個になる。RailPropertyの `autoSplit` は有効なまま保持する。
- 上書きされた既存レール自体の撤去・整合性修復は行わない。既存レールが結果的に走行不能になることを許容する。
- Undoは生成した論理レールだけを撤去し、生成時に破壊したブロックや他レールは復元しない。

## 描画

- 未確定位置には `selectCursor` と `selectCursorMarker` を表示する。
- 確定位置には `selectedCursor` と、生成予定RailPositionの `direction` に対応する `marker0`〜`marker7` を表示する。
- 1点以上選択したときは、始点から現在位置または終点まで `selectedLine` を表示する。
- SRB3由来モデルに含まれるその他のオブジェクトは、必要な機能が実装されるまで登録・描画しない。

## 実機検証

破壊的な生成を行うため、必ずバックアップ済みテストワールドを使用します。

1. 空間点同士で短いレールと複数チャンクを跨ぐレールを生成する。
2. 手に持ったレールモデル、位置、方向、即時描画、再入場後の保存を確認する。
3. PとCtrl+Pの各設定でカーソル、marker、生成形状を確認する。
4. 既設端部同士を接続し、3本すべての接続方向から列車を走行させる。
5. 既設端部と空間点の生成が安全に拒否されることを確認する。
6. 道床、通常ブロック、別レールコアを横切り、強制置換数と生成後の状態を確認する。
7. Ctrl+Zで生成レールが撤去され、選択状態が戻ること、破壊済みブロックは戻らないことを確認する。
8. `latest.log` の `[SuperRailBuilderX builder1]`、例外、`Rail not found` を共有する。
