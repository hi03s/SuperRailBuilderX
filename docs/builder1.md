# builder1 基本仕様・検証項目

## 実装範囲

`SuperRailBuilderX_builder1` は、始点と終点の2点からKaizPatchXの自動分割設定を持つレールを生成する最初のツールです。

- 右クリックで始点、終点の順に選択する。
- 左クリックで最後の選択を1段階取り消す。
- Cで選択だけを全解除し、スナップ、空中高さ、半径固定などの設定は維持する。
- Ctrl+Cで選択、スナップ、空中高さ、半径固定、勾配、専用Undoを初期状態へ完全リセットする。
- レールアイテムを手に持ってEnterを押すと、そのRailPropertyを複製し、`autoSplit=true` として生成する。
- Pで位置・角度スナップを切り替える。初期値はOFF。
- Ctrl+Pで角度を1度、5度、15度の順に切り替える。初期値は5度。
- Oで曲線半径固定を切り替える。←/→で1 m、Ctrl+←/→で100 mずつ変更し、1〜10000 mに制限する。10000 mは直線（半径∞）として扱う。
- ↑/↓で自由点の高さを1 m、Ctrl+↑/↓で1/16 mずつ変更する。既設端部から自由点へ伸ばす状態、または自由点と既設端部を選択済みの状態では、Ctrlなしの↑/↓を終端勾配の1‰変更へ切り替える。
- Ctrl+Zでbuilder1が直前に生成した論理レールを1回だけ撤去し、生成前の選択状態へ戻す。
- Hで操作説明、Qでツールを終了する。

## 座標と方向

- 自由点の精密Y座標には、通常レールの高さ1/16ブロックを加える。
- スナップOFFでは自由点を0.001ブロック単位へ丸める。
- スナップONの自由始点は0.5ブロック格子へ丸める。
- スナップONの自由終点は、始点を基準に水平方向角を現在の角度刻みへ、3次元距離を0.5 m単位へ丸める。終点はワールド座標の0.5ブロック格子へ再度丸めない。
- 自由点同士は、始点から終点へ向くアンカーと、その反対を向く終点アンカーを作る。`direction` はアンカー角に最も近い8方向を設定する。
- RTMのYawは0度が+Z、90度が+Xである。自由点の`direction`もこの規約で算出する。
- 既設端部を始点にすると、自由終点の初期Y座標を始点アンカー勾配の延長直線上へ置き、終端勾配の初期値もその勾配にする。既設端部を新しい始点として選び直すたびに初期値をリセットする。
- 自由点→既設端部の2点選択で↑/↓を操作した場合は、自由点側（選択上の始点）のアンカー勾配を変更する。
- サーバーで生成するときは選択順に関係なく、精密Y座標が低いRailPositionをRailMapの生成起点にする。

## 曲線半径固定

- 未選択でOを押した場合は10000 m（直線）から開始する。
- 1点以上選択済みでOを押した場合は、現在プレビューしている曲線半径を整数mへ丸めて固定する。直線または半径を計算できない場合は10000 mとする。
- 1点選択中は、始点から視線先までの水平距離を弧長として、固定半径と始点接線から自由終点を計算する。カーソルが始点接線の左右どちらにあるかでカーブ方向を決める。
- 2点選択済みでOを押した場合は終点座標と現在の曲線形状を変更せず、固定値だけを今後の設定として変更する。
- レール生成後も半径固定ONと設定半径を維持し、OでOFFまたはCtrl+Cで完全リセットするまで連続利用できる。
- 半径固定中は視線先へ常に固定値を表示し、10000 mでは`curvePanel_infinity`を表示する。

## 既設レール端部との接続

- 空間点同士は生成できる。
- 既設端部と空間点の組み合わせは生成できる。既設端部の接線を固定し、SRB3と同じアンカー交点・中心角・半径の計算から正円近似ベジェを作る。
- 既設端部同士は生成できる。既存コアを上書きしないよう、元RailPositionの`blockX/Z`と`REVISION × 2`から求めるSRB3準拠の接続ブロック側に、反転したRailPositionを作成する。
- 新しいRailPositionは精密座標を既設端部と一致させ、`direction` とアンカー角を180度反転し、アンカー勾配の符号も反転する。
- 既設端部同士の両アンカーは、SRB3と同じく端点間距離の2/3を仮アンカー長としてベジェ長を近似し、その曲線長の1/3を最終アンカー長にする。
- `RailPosition#getNeighborPos()`は自由化後の精密端点を基準にするため、マーカーとして接続するブロック座標の決定には使用しない。

## 自由点のマーカーブロック

RailPositionの精密端点がブロック境界・辺・角にある場合、同じ端点を表せるマーカーブロックはdirectionによって変わります。builder1は精密端点から生成予定のアンカー方向へ微小量進めた座標を切り捨て、レールが入っていく側の所有ブロックを選びます。

- 方向決定前の自由点を単純な小数点切り捨てだけで確定しない。
- 1点目と2点目の向きが決まった時点で、両方のマーカーブロック位置を再計算する。
- クライアント表示とサーバーが生成するRailPositionで同じ逆算規則を使用する。

## 破壊的な生成

builder1はクリエイティブ敷設に近い試験方針として、生成経路上のブロックを道床へ強制置換します。他レールの道床・コアを含む既存ブロックを原則として保護しません。

- 複数セクションでは `RailChunkSectioner.split` の各RailMapSectionを直接敷設し、セクションコアを生成する。
- 短いレールなど分割結果が1セクションの場合は、KaizPatchX標準と同様に通常コア1個になる。RailPropertyの `autoSplit` は有効なまま保持する。
- 既設コアを`World#setBlock`で直接道床へ置換すると、旧コアの破壊処理が新しい道床まで空気化して生成に失敗する。このため経路上の他レールコアを事前収集し、対象コアブロックを先に空気化して標準破壊処理を完了させてから道床を置く。builder1から論理レール撤去APIは直接呼ばない。
- 接続対象自身の論理レールのコアへ生成経路が戻る場合は、その接続レールを破壊せず`connection_core_conflict`で停止する。他レールのコアは破壊され、通常道床も新設側の所有情報へ置換され得る。
- Undoは生成した論理レールだけを撤去し、生成時に破壊したブロックや他レールは復元しない。

## 描画

- 未確定位置には `selectCursor` を表示する。`selectCursorMarker`は既設レール端部など、選択前からマーカーブロック位置が確定している候補だけに表示し、方向未確定の自由点には表示しない。
- 確定位置には `selectedCursor` と、生成予定RailPositionの `direction` に対応する `marker0`〜`marker7` を表示する。
- `selectCursor` / `selectedCursor` は精密端点へ表示し、`selectCursorMarker` / `marker0`〜`marker7` は通常のマーカーブロック設置位置へ表示する。既設端部ではSRB3準拠の接続ブロック中央を使う。
- 1点以上選択したときは、生成に使うYaw・Pitch・アンカー長から3次ベジェ曲線を計算し、始点から現在位置または終点まで `selectedLine` を分割表示する。
- 曲線中央にSRB3モデルの`curvePanel_*`を使って左右方向と近似半径mを表示する。既設端部と自由点の正円近似に加え、既設端部同士のベジェも両端接線から近似半径を求める。半径固定中の10000 mは視線先で∞表示する。
- プレビュー中は両端に`slopePanel_*`を使ってアンカー勾配の絶対値を‰表示する。
- SRB3由来モデルに含まれるその他のオブジェクトは、必要な機能が実装されるまで登録・描画しない。

## 実機検証

破壊的な生成を行うため、必ずバックアップ済みテストワールドを使用します。

1. 空間点同士で短いレールと複数チャンクを跨ぐレールを生成する。
2. 手に持ったレールモデル、位置、方向、即時描画、再入場後の保存を確認する。
3. PとCtrl+Pの各設定でカーソル、marker、生成形状を確認する。
4. 既設端部同士を接続し、元レールの道床・コアを壊さず、3本すべての接続方向から列車を走行させる。
5. 既設端部と空間点を両方の選択順で生成し、固定端へ滑らかにつながる正円近似、半径表示、自由端markerの向きと所有ブロックを確認する。
6. 自由点では`selectCursorMarker`が非表示、既設端部候補では正しい接続ブロックに表示されることを確認する。
7. Oと矢印キーで半径を固定し、左右カーブ、10000 mの∞表示、2点選択後の座標維持、生成後の設定維持、Ctrl+Cの完全リセットを確認する。
8. ↑/↓とCtrl+↑/↓で空中高さを変更し、既設端始点では初期勾配の延長、1‰調整、自由点→既設端で自由点側勾配が変わること、両端パネル、低い側起点を確認する。
9. 道床、通常ブロック、別レールコアを横切り、交差コアの二段階置換ログと生成後の状態を確認する。接続対象自身へ曲線が戻る場合は安全停止することも確認する。
10. Ctrl+Zで生成レールが撤去され、選択状態が戻ること、破壊済みブロックは戻らないことを確認する。
11. `latest.log` の `[SuperRailBuilderX builder1]`、例外、`Rail not found` を共有する。

## 実装上の注意

- Minecraft 1.7.10の`World#setBlock`は、要求後のブロック状態が目的どおりでも「状態変更なし」などで`false`を返す場合がある。builder1は戻り値だけを生成失敗条件にせず、設置後のTileEntity型を検証する。
- 自由点RailPositionにはプレビューと同じ水平アンカー長を明示的に保存する。2点直線では端点間距離の1/3、既設端部同士ではSRB3方式で仮ベジェ長から最終値を求める。
- 道床化できないブロックで生成に失敗した場合に備え、変更前後のブロック、メタデータ、`setBlock`結果、TileEntityを診断ログへ残す。現段階では生成途中の破壊済みブロックを復元しない。
- 2026-09-02のログでは、既設コアを直接置換した失敗時に`before=BlockLargeRailCore/1`、`after=BlockAir/0`が記録された。コア破壊の副作用が道床設置後に到達する順序問題であり、交差の幾何形状だけでは成功・失敗を分類できない。
