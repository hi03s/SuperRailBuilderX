# builder1 基本仕様・検証項目

## 実装範囲

`SuperRailBuilderX_builder1` は、始点と終点の2点からKaizPatchXの自動分割設定を持つレールを生成する最初のツールです。

- 右クリックで始点、終点の順に選択する。
- 左クリックで最後の選択を1段階取り消す。
- Cで選択だけを全解除し、スナップ、空中高さ、半径固定などの設定は維持する。
- Ctrl+Cで選択、スナップ、空中高さ、半径固定、勾配、縦曲線半径を初期状態へ完全リセットする。直前生成の専用Undoは維持する。
- レールアイテムを手に持ってEnterを押すと、そのRailPropertyを複製し、通常は`autoSplit=true`として生成する。自動分割が必要な経路で既設のKaizPatchXセクションコアだけを横切る場合は、交差相手を保護するため新設側を単一の通常レール（`autoSplit=false`）として生成し、成功時はその旨をチャットへ表示する。この交差生成は64 m以下に制限する。
- Pで位置・角度スナップを切り替える。初期値はOFF。
- Ctrl+Pで角度を1度、5度、15度の順に切り替える。初期値は5度。
- Oで曲線半径固定を切り替える。←/→で1 m、Ctrl+←/→で100 mずつ変更し、1〜10000 mに制限する。10000 mは直線（半径∞）として扱う。各矢印キーは長押しリピートに対応する。
- 既設端部を含まない状態では、↑/↓で自由点の高さを1 m、Ctrl+↑/↓で1/16 mずつ変更する。
- 既設端部から自由点へ伸ばす状態、または自由点と既設端部を選択済みの状態では、↑/↓で自由端の目標勾配を1‰、Ctrl+↑/↓で縦曲線半径を1000 mずつ変更する。縦曲線半径の初期値と下限は1000 mで、変更時はチャット欄へ表示する。各矢印キーは長押しリピートに対応する。
- Fで空中高さオフセットだけを0へ戻す。
- Ctrl+Zでbuilder1が直前に生成した1本、または縦曲線分割後の2本の論理レールをまとめて撤去し、生成前の選択状態へ戻す。
- Hで操作説明、Qでツールを終了する。
- 水平曲線半径と勾配の変更値はモデル表示で確認できるため、O・←/→・勾配変更のたびにはチャットへ通知しない。縦曲線半径には専用パネルがまだないため、Ctrl+↑/↓で変更した値をチャットへ通知する。

## 座標と方向

- 自由点の精密Y座標には、通常レールの高さ1/16ブロックを加える。
- スナップOFFでは自由点を0.001ブロック単位へ丸める。
- スナップONの自由始点は0.5ブロック格子へ丸める。
- スナップONの自由終点は、始点を基準に水平方向角を現在の角度刻みへ、3次元距離を0.5 m単位へ丸める。終点はワールド座標の0.5ブロック格子へ再度丸めない。
- 自由点同士は、始点から終点へ向くアンカーと、その反対を向く終点アンカーを作る。`direction` はアンカー角に最も近い8方向を設定する。
- RTMのYawは0度が+Z、90度が+Xである。自由点の`direction`もこの規約で算出する。
- 既設端部を始点にすると、自由終点の仮Y座標を始点アンカー勾配の延長直線上へ置き、終端勾配の初期値もその勾配にする。プレビューと生成に使う最終Y座標は、空中高さオフセットではなく、始点勾配・目標勾配・縦曲線半径・水平経路長から求め直す。既設端部を新しい始点として選び直すたびに目標勾配をリセットする。
- 自由点→既設端部の2点選択で↑/↓を操作した場合は、自由点側（選択上の始点）のアンカー勾配を変更する。
- サーバーで生成するときは選択順に関係なく、精密Y座標が低いRailPositionをRailMapの生成起点にする。

## 曲線半径固定

- 未選択でOを押した場合は10000 m（直線）から開始する。
- 1点以上選択済みでOを押した場合は、現在プレビューしている曲線半径を整数mへ丸めて固定する。直線または半径を計算できない場合は10000 mとする。
- 1点選択中は、始点から視線先までの水平距離を弧長として、固定半径と始点接線から自由終点を計算する。カーソルが始点接線の左右どちらにあるかでカーブ方向を決める。
- 2点選択済みでOを押した場合は終点座標と現在の曲線形状を変更せず、固定値だけを今後の設定として変更する。
- レール生成後も半径固定ONと設定半径を維持し、OでOFFまたはCtrl+Cで完全リセットするまで連続利用できる。
- 半径固定中は視線先へ常に固定値を表示し、10000 mでは`curvePanel_infinity`を表示する。

## 既設レール端部との接続

- 空間点同士は生成できる。
- 既設端部と空間点の組み合わせは生成できる。既設端部の接線を固定し、SRB3と同じアンカー交点・中心角・半径の計算から正円近似ベジェを作る。
- 既設端部同士は生成できる。既存コアを上書きしないよう、元RailPositionの`blockX/Z`と`REVISION × 2`から求めるSRB3準拠の接続ブロック側に、反転したRailPositionを作成する。
- 新しいRailPositionは精密座標を既設端部と一致させ、`direction` とアンカー角を180度反転し、アンカー勾配の符号も反転する。
- 既設端部同士の両アンカーは、SRB3と同じく端点間距離の2/3を仮アンカー長としてベジェ長を近似し、その曲線長の1/3を最終アンカー長にする。
- `RailPosition#getNeighborPos()`は自由化後の精密端点を基準にするため、マーカーとして接続するブロック座標の決定には使用しない。

## 自由点のマーカーブロック

RailPositionの精密端点がブロック境界・辺・角にある場合、同じ端点を表せるマーカーブロックはdirectionによって変わります。builder1は精密端点から生成予定のアンカー方向へ微小量進めた座標を切り捨て、レールが入っていく側の所有ブロックを選びます。

- 方向決定前の自由点を単純な小数点切り捨てだけで確定しない。
- 1点目と2点目の向きが決まった時点で、両方のマーカーブロック位置を再計算する。
- クライアント表示とサーバーが生成するRailPositionで同じ逆算規則を使用する。

## 破壊的な生成

builder1はクリエイティブ敷設に近い試験方針として、生成経路上の通常ブロックを道床へ強制置換します。ただし実機ログで他レール全体の破壊を確認したため、既設レールコアと接続対象レールは保護します。

- 複数セクションでは `RailChunkSectioner.split` の各RailMapSectionを直接敷設し、セクションコアを生成する。
- 短いレールなど分割結果が1セクションの場合は、KaizPatchX標準と同様に通常コア1個になる。RailPropertyの `autoSplit` は有効なまま保持する。
- 既設コアを`World#setBlock`や空気化で置換すると、コアの`breakBlock`が論理レール全体を撤去するため、交差相手を破壊する。builder1から既設コアの置換や論理レール撤去APIは呼ばない。
- 経路上の未保護コアがKaizPatchXのセクションコアだけで、生成始点自体は占有されていない場合、チャンク分割を行わず通常レールを生成し、交差位置の既設セクションコアを道床で上書きしない。単一コアのロード範囲を過度に広げないため64 mを超える場合は`normal_rail_too_long`で停止する。通常コアとの衝突や複数種類のコア衝突は従来どおり`rail_core_conflict`で停止する。
- RTM標準マーカーと同様に、既設の通常道床との重なりは許可し、同じ道床ブロックを新設側の所有情報へ更新する。既設レールコアとの重なりは、接続対象か他レールかにかかわらずコアを破壊せず`rail_core_conflict`で停止する。
- 自動分割の内部セクションコア予定位置が既設道床と重なる場合は、同じチャンク・同じ区間の空いている経路ブロックへコア位置を移す。候補がなければ`section_core_conflict`で安全停止する。
- 道床をセクションコアへ置換する直前に、道床の所有座標をそのブロック自身へ戻す。複数区間の道床設置で所有情報が別区間へ上書きされていても、コア化の`breakBlock`が生成途中の新レールを誤って全撤去しないためのガードである。
- Undoは生成した論理レールだけを撤去し、生成時に破壊したブロックや他レールは復元しない。

## 縦曲線

- ↑/↓で指定する勾配は自由端における最終目標値として扱う。
- Ctrl+↑/↓で指定する縦曲線半径は初期値1000 m、1000 m刻み、下限1000 mとする。設定値は生成後も維持し、Ctrl+Cで1000 mへ戻す。
- 既設端側の勾配から目標勾配までを指定半径の正円近似ベジェで変化させ、残距離を目標勾配の直線として生成する。直線区間が存在する場合は、水平ベジェもDe Casteljau分割して同じ平面線形を保った2本の論理レールにする。
- 正円近似区間だけで選択端点へ到達し、利用できる距離では目標勾配まで変化できない場合は、到達可能な勾配までの正円近似レール1本だけを生成する。
- 例として20‰から0‰へ1000 m半径で遷移する場合、水平距離は約20 mで水平へ到達する。それより長ければ到達点で分割して残りを水平にし、短ければ0‰へ届かない正円近似区間だけにする。
- 内部分割点の両RailPositionには、RTMの通常マーカー接続と同じく互いに対応する別々の所有ブロックを割り当てる。
- 正円近似区間と直線区間へ分割されるプレビューでは、分割位置に`cantLine`を表示する。
- 縦曲線と直線の2本を生成中に後半が失敗した場合は、先に生成した論理レールを撤去する。Ctrl+Zでも2本を1回分として逆順に撤去する。

## 描画

- 未確定位置には `selectCursor` を表示する。`selectCursorMarker`は既設レール端部に加え、スナップONでは自由点にも常時表示し、選択中のブロック内位置を確認できるようにする。スナップOFFで方向未確定の自由点には表示しない。
- 確定位置には `selectedCursor` と、生成予定RailPositionの `direction` に対応する `marker0`〜`marker7` を表示する。
- `selectCursor` / `selectedCursor` は精密端点へ表示し、`selectCursorMarker` / `marker0`〜`marker7` は通常のマーカーブロック設置位置へ表示する。既設端部ではSRB3準拠の接続ブロック中央を使う。
- 1点以上選択したときは、生成に使うYaw・Pitch・アンカー長から3次ベジェ曲線を計算し、始点から現在位置または終点まで `selectedLine` を分割表示する。
- 曲線中央にSRB3モデルの`curvePanel_*`を使って左右方向と近似半径mを表示する。既設端部と自由点の正円近似に加え、既設端部同士のベジェも両端接線から近似半径を求める。半径固定中の10000 mは視線先で∞表示する。
- プレビュー中は両端に`slopePanel_*`を使ってアンカー勾配の絶対値を‰表示する。
- SRB3由来モデルに含まれるその他のオブジェクトは、必要な機能が実装されるまで登録・描画しない。

## 実機検証

破壊的な生成を行うため、必ずバックアップ済みテストワールドを使用します。

1. 空間点同士で短いレールと複数チャンクを跨ぐレールを生成する。
2. 手に持ったレールモデル、位置、方向、即時描画、再入場後の保存を確認する。
3. PとCtrl+Pの各設定でカーソル、marker、生成形状を確認する。
4. 既設端部同士を接続し、元レールの道床・コアを壊さず、3本すべての接続方向から列車を走行させる。
5. 既設端部と空間点を両方の選択順で生成し、固定端へ滑らかにつながる正円近似、半径表示、自由端markerの向きと所有ブロックを確認する。
6. スナップOFFの自由点では`selectCursorMarker`が非表示、既設端部候補とスナップONの自由点では正しいマーカーブロックに表示されることを確認する。
7. Oと矢印キーで半径を固定し、プレイヤーの向きと同じ起点接線、左右カーブ、10000 mの∞表示、長押し、2点選択後の座標維持、生成後の設定維持を確認する。
8. 既設端を含まない状態では↑/↓とCtrl+↑/↓の長押しで空中高さを変更し、Fで0へ戻ることを確認する。既設端を含む状態では空中高さの影響がなく、↑/↓で目標勾配、Ctrl+↑/↓で縦曲線半径が変わり、半径だけチャット表示されることを確認する。
9. 道床、通常ブロック、別レールコアを横切り、通常道床交差では生成されることを確認する。KaizPatchXセクションコアとの交差では`section-core crossing will be created as one normal rail`と`crossing section core preserved`が出て新設側だけが通常レールとなり、両レールを走行できることを確認する。通常コア交差は破壊せず安全停止すること、内部セクションコア予定位置が道床と重なる場合は`section core relocated`が出て両レールが残ることも確認する。
10. Ctrl+Zで生成レールが撤去され、選択状態が戻ること、破壊済みブロックは戻らないことを確認する。
11. +X/+Zと-X/-Zの直線を同じ道床幅で生成し、片側の凹みや余分な張り出しがなく左右対称になることを確認する。
12. 20‰→0‰などの勾配変更で、指定した縦曲線半径に応じた正円近似区間＋直線区間の2本が生成され、分割位置に`cantLine`が表示されることを確認する。接続点を列車が通過できること、距離不足時は正円近似1本になること、Ctrl+Zで両方が撤去されることも確認する。
13. `latest.log` の `[SuperRailBuilderX builder1]`、`vertical profile plan`、例外、`Rail not found` を共有する。

## 実装上の注意

- Minecraft 1.7.10の`World#setBlock`は、要求後のブロック状態が目的どおりでも「状態変更なし」などで`false`を返す場合がある。builder1は戻り値だけを生成失敗条件にせず、設置後のTileEntity型を検証する。
- 自由点RailPositionにはプレビューと同じ水平アンカー長を明示的に保存する。2点直線では端点間距離の1/3、既設端部同士ではSRB3方式で仮ベジェ長から最終値を求める。
- 通常生成では両RailPositionの`anchorLengthVertical`へ`anchorLengthHorizontal`と同じ値を設定する。勾配指定時の正円近似区間には`radius × 4/3 × tan(angle/4)`を設定し、直線勾配区間は両端を0にする。両方が0の場合、RTMの`RailMapBasic`は端点Pitchによらず垂直線形を直線補間する。
- RTMの道床幅計算はYaw±90度の`sin/cos`を切り捨てるため、0になるべき値が負の極小値だと、-X/-Z方向の整数境界で片側だけ隣ブロックへ落ちる。builder1の敷設判定と配置では0・±1近傍を厳密値へ正規化してから道床座標を列挙する。また、RTM標準の端部隣接除外は中心1ブロックだけを除くため、負方向の境界では同じ幅サンプルの側方ブロックが残って凹型になり得る。builder1では端部隣接座標に属する幅サンプル全体を除外する。専用Undoは正規化側だけに存在する道床も所有TileEntityを確認して撤去する。
- 道床化できないブロックで生成に失敗した場合に備え、変更前後のブロック、メタデータ、`setBlock`結果、TileEntityを診断ログへ残す。現段階では生成途中の破壊済みブロックを復元しない。
- 2026-09-02のログでは、既設コアを直接置換した失敗時に`before=BlockLargeRailCore/1`、`after=BlockAir/0`が記録された。コア破壊の副作用が道床設置後に到達する順序問題であり、交差の幾何形状だけでは成功・失敗を分類できない。
- 次のログではセクションコア化の直前が新設済み`BlockLargeRailBase`でも、置換後に空気化する例を確認した。複数区間の道床が同じ座標を共有して所有コア座標を上書きすると、後からコア化する際に先に生成済みの区間コアを取得して新しい論理レール全体を破壊し得る。このためコア化直前に所有座標を自分自身へ戻す。
