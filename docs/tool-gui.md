# ツール状態GUI

全6ツールで画面上端のツール名と右上の大アイコンを表示する。タイトルと状態文字は影付き白文字。状態行は大アイコンの下、右端の16 px列へ上から順に配置し、文字右端をアイコンの左4 pxにそろえる。Minecraftの別画面を開いている間は表示しない。操作中プレイヤーだけが表示対象で、描画pass=0・material=0で1回描画する。

`gui_base.png`は16×16グリッド。背景は(3,0)=OFF、(3,1)=ON、(3,2)=情報表示。状態アイコンは背景の上に重ねる。

| ツール | 上から並ぶ状態行 | 表示条件・更新元 |
| --- | --- | --- |
| レール生成A | グリッド(4,0)、カーブ(4,1)、レール長(4,2) | 距離の角度/ブロック、固定またはプレビュー半径、選択中のプレビュー長。従来どおり |
| 線路分割 | レール長(4,2)を2行 | 分割候補カーソルが表示されるホバー中、または分割点選択後に前後区間の予想長を小数2桁mで表示。対象なし/無効な候補は空欄 |
| 線路移動 | グリッド(4,0) | 0.1 mスナップのON/OFF背景のみ。文字なし |
| 複線コピー | レール(4,2) | `間隔:4.0m`のように現在の間隔を小数1桁で常時表示。間隔変更/リセットのチャット出力は廃止 |
| カント整形 | 速度(5,0)、レール(4,2) | `設計速度:100km/h`、`種類:1067mm`などを常時表示。速度は0〜999 km/hで、カーソル先には表示しない。種類は在来線/新幹線などの区別も含む。種類変更時の最大カント付きチャット出力は維持 |
| 分岐生成 | グリッド(4,0)、カーブ(4,1)、レール長(4,2) | レール生成Aと同様にOFF/距離/ブロックを切替。距離では角度、ブロックでは`ブロック`を表示。固定ONなら設定半径、固定OFFで分岐候補があれば現在のプレビュー半径。無限大は`直線`。起点選択後に新線側プレビューの3D長を小数2桁mで表示。終点候補がない場合は0.00 m |

分割長は既存論理RailMapの長さと分割比率から求める。分岐長は描画済み48分割の3D折線を集計する概算で、元レール側の残存区間は含めない。GUIのためにRailMapを新規生成したりワールドへ書き込んだりしない。

共通実装は`src/common/assets/minecraft/scripts/superrailbuilderx/SRBXToolGui.ts`。レール生成Aで確認済みの霧隔離、行列・属性の個別保存/復元、1.12.2のGlStateManagerキャッシュ同期を移設した。GLのPush/Popを使わず、旧Java 8u51のtry/finally内continue問題も回避する。異常時は`[SuperRailBuilderX GUI] tool=...`とstage/errorを記録してGUIを停止する。

## 検証

- `pnpm build`で全ターゲットをビルドし、`pnpm test:gui`で描画状態復元、アイコン座標、各設定文字、分割のホバー/選択/非候補、表示pass、分岐の3D長を確認する。
- ゲーム同梱Javaの`jjs -scripting tests/srbx_patch/builder1_gui_nashorn.test.js`で全6ツールの生成GUIを実行する。GL呼出は模擬であり、実GPUの検証とは区別する。
- 実機では更新ZIPへ置換して再起動し、KaizPatch/AEで全ツールの表示、設定変更、選択/解除、別画面の開閉、ツール終了とレール描画を確認する。異常時はツール名、操作手順、`logs/latest.log`を共有する。
