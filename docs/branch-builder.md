# 分岐生成ツール 基本仕様・検証項目

## 操作と生成方式

1. 既設レールの中央ではレール分割ツールと同じ約0.5 m間隔の候補、端部では正確なRailPositionを右クリックする。中央分割後の両区間は3 m超とする。
2. レール生成Aと同様に自由点または別レール端点を右クリックし、選択点からの理論RailMapを決める。
3. `Enter`で、中央選択時は元レールを分割して新線側の半区間と新線を単純分岐へ合成する。端部選択時は選択端点を根元、元レールの反対端を本線、新しい終点を側線とする単純分岐へ元レールを組み替える。

`P`で位置スナップ、`Ctrl+P`で角度スナップ、`O`で曲線半径固定、`←` / `→`で1 m、`Ctrl+←` / `Ctrl+→`で100 mずつ半径を変更する。左クリックは1段階戻る。`Ctrl+Z`は生成した分岐と通常半区間を撤去し、中央・端点選択とも元レールを復元する。

Enter時にレールを持っていればそのモデルを分岐へ使い、持っていなければ分割元モデルを使う。残る通常半区間は分割元モデルを保持する。道床はレール移動・builder1と同じ列挙、既設コア保護、所有更新規則を使う。

単純分岐で共用される根元RailPositionは、分割元半区間の接線とアンカー長を保持する。新線プレビュー用のアンカー長で本線側を上書きせず、短い本線側で曲線が中央付近まで過伸長することを防ぐ。曲線半径パネルはアルファブレンドを有効化し、透明部分を黒く表示しない。

生成時はベースレールのカントを全端点で0にし、その両端へ接続している既設レールの接続端点、新線の接続先端点、生成物も0に揃える。`Ctrl+Z`では変更した既設レールのカントを生成前へ戻す。

分岐レール、自動分割状態が不正なレール、在線中のレール、勾配または縦曲線を持つレールは選択・生成できない。全長6 m以下は中央分割できないが、端点起点には使用できる。接続先として選ぶ既設レールも水平な通常レールに限る。サーバーは対象キー、分割比、端点、水平性、在線状態を再検証する。ワールド変更はKaizPatchX限定。

KaizPatchX同梱の`LibRenderRail.js`は、自由配置された分岐根元のオフセットを外側の描画変換と`renderRailMapDynamic`内で二重加算する。このためRailMapと台車追従が正しくても、標準モデルの根元から中央までだけ描画がずれる。全レールモデルへ影響する共通スクリプトのため、本プロジェクトでは上書きせずKaizPatchX側の修正を待つ。

## 実機確認

1. 直線と水平曲線の途中を選択し、新線側に応じて正しい半区間が分岐へ合成される。
2. 中央候補と両端点を選び、端点選択では選択端を根元として元レールの線形を本線側に保持した分岐が生成される。
3. 自由点、別レール端点、スナップ、半径固定の各プレビューと実生成が一致する。
4. 手持ちレールありでは手持ちモデル、なしではベースレールのモデルになる。
5. 分岐の切替、両経路の走行、道床所有、描画更新が正常である。
6. 生成後にベース・接続端・生成物のカントが0となり、`Ctrl+Z`で生成物と既設レールのカントが元へ戻る。
7. 勾配・縦曲線・既存分岐・在線中・短すぎる中央候補が選択または適用を拒否される。
