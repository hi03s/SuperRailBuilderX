# 分岐生成ツール 基本仕様・検証項目

## 操作と生成方式

1. レール分割ツールと同じ約0.25 m間隔の候補から、既設レール上の分割点を右クリックする。分割後の両区間は3 m超とする。
2. レール生成Aと同様に自由点または別レール端点を右クリックし、分割点からの理論RailMapを決める。
3. `Enter`で元レールを分割する。新線が向く側の既設半区間と新線を単純分岐レールへ合成し、反対側を通常レールとして残す。

`P`で位置スナップ、`Ctrl+P`で角度スナップ、`O`で曲線半径固定、`←` / `→`で1 m、`Ctrl+←` / `Ctrl+→`で100 mずつ半径を変更する。左クリックは1段階戻る。`Ctrl+Z`は生成した通常半区間と分岐を撤去し、分割元レールを復元する。

Enter時にレールを持っていればそのモデルを分岐へ使い、持っていなければ分割元モデルを使う。残る通常半区間は分割元モデルを保持する。道床はレール移動・builder1と同じ列挙、既設コア保護、所有更新規則を使う。

分岐レール、自動分割状態が不正なレール、全長6 m以下、在線中のレール、勾配または縦曲線を持つレールは選択・生成できない。接続先として選ぶ既設レールも水平な通常レールに限る。サーバーは対象キー、分割比、端点、水平性、在線状態を再検証する。ワールド変更はKaizPatchX限定。

## 実機確認

1. 直線と水平曲線の途中を選択し、新線側に応じて正しい半区間が分岐へ合成される。
2. 自由点、別レール端点、スナップ、半径固定の各プレビューと実生成が一致する。
3. 手持ちレールありでは手持ちモデル、なしでは分割元モデルになる。
4. 分岐の切替、両経路の走行、道床所有、描画更新が正常である。
5. `Ctrl+Z`で通常半区間と分岐が消え、元レール、モデル、信号、サブレールが復元される。
6. 勾配・縦曲線・既存分岐・在線中・短すぎるレールが選択または適用を拒否される。
