# SuperRailBuilderX ツール概要・操作ガイド

対象リリース: **alpha-0.1.0**

## 使用前に必ず確認してください

> [!CAUTION]
> **対象ワールドのバックアップを必ず取ってから使用してください。**
>
> 各ツールはレール、道床、RailPositionを直接変更し、機能によっては既設レールを撤去して再生成します。不具合や未対応の配置条件により、レールの消失、走行不能、ワールドデータの破損が発生する可能性があります。

- 初回はバックアップ済みのテストワールドで動作を確認してください。
- 列車が変更対象レール上にいない状態で操作してください。
- 適用中はツールを壊したり、ワールドから退出したりしないでください。
- エラーが表示された場合は連続操作を止め、ワールドを保存せず終了することも検討してください。

## 導入と起動

1. Minecraft 1.7.10へKaizPatchX 1.10.3以降を導入します。
2. SuperRailBuilderXの配布パックを`mods`フォルダーへ入れます。
3. 自動車モデル選択画面から`SuperRailBuilderX_builder1`（機能名: レール生成A）または目的の`SuperRailBuilderX`ツールを選び、地面へ設置します。
4. 設置したツールを右クリックして使用を開始します。

## 共通操作

| 操作       | 動作                                     |
| ---------- | ---------------------------------------- |
| 右クリック | 対象の選択、選択状態の切替、位置の確定   |
| 左クリック | 選択または確定を1段階戻す                |
| `Enter`    | プレビューした処理を適用                 |
| `Ctrl+Z`   | そのツールで直前に適用した処理を取り消す |
| `H`        | チャット欄へ操作ヘルプを表示             |
| `Q`        | ツールを終了                             |

Undo情報はツールとサーバースクリプトのメモリに保持されます。ツール終了、スクリプト再読み込み、サーバー再起動後のUndoはできません。Undoはワールド全体の変更を戻す機能ではなく、対象ツールによる直前の1操作だけが対象です。

## レール生成A

### 概要

始点と終点を指定して、新しいレールを敷設します。自由点だけでなく既設レール端点へ接続でき、曲線半径固定、勾配、縦曲線、地上高合わせに対応します。

### 基本操作

1. 始点へ視線を合わせて右クリックします。
2. 終点へ視線を合わせて右クリックします。
3. プレビューを確認し、`Enter`で生成します。

手にレールを持っている場合は、そのモデルと設定を使用します。手に持っていない場合でも、既設レール端点が選択されていれば接続先レールのモデルを使用できます。

| 操作                | 動作                                       |
| ------------------- | ------------------------------------------ |
| `P`                 | ブロック位置へのスナップON/OFF             |
| `Ctrl+P`            | スナップ角度を変更                         |
| `O`                 | 曲線半径固定ON/OFF                         |
| `←` / `→`           | 固定半径を1 m変更                          |
| `Ctrl+←` / `Ctrl+→` | 固定半径を100 m変更                        |
| `↑` / `↓`           | 自由点の高さを1 m、または目標勾配を1‰変更  |
| `Ctrl+↑` / `Ctrl+↓` | 縦曲線半径を1000 m変更                     |
| `F`                 | 空中高さをリセット                         |
| `I`                 | 0‰の自由端を地上の通常レール高さへ合わせる |
| `C`                 | 選択を解除                                 |
| `Ctrl+C`            | 選択と設定を初期化                         |

生成時に重なる通常ブロックや通常道床は置換される場合があります。既設レールコアは保護されますが、交差やチャンク境界を含む複雑な配置では特にバックアップを確認してください。

## 複線コピーツール

### 概要

既設レールを論理レール単位で選択し、カーソル側へ指定間隔の平行レールを生成します。複数レールの一括選択と、間隔の倍数位置への複数列生成に対応します。

### 基本操作

1. コピー元レールを右クリックして選択します。選択済みレールを右クリックすると解除します。
2. `←` / `→`で複線間隔を調整します。
3. 生成したい側の空間へ視線を向けて右クリックし、位置と本数を固定します。
4. `Enter`で一括生成します。

| 操作      | 動作                    |
| --------- | ----------------------- |
| `←` / `→` | 複線間隔を0.1 mずつ変更 |
| `C`       | 選択と状態を初期化      |

Enterを押した時にレールを持っていればそのモデルを使い、持っていなければコピー元モデルを使います。移動先の端点付近に既設レール端点がある場合は接続を試みます。

## 線路分割ツール

### 概要

既設の1本の論理レールを指定位置で2本へ分割します。分割後の予定長を表示し、通常レールとKaizPatchXの自動分割レールに対応します。

### 基本操作

1. 分割するレールへ視線を合わせます。
2. 黄色い強調表示とカーソルを確認し、右クリックで分割位置を確定します。
3. 表示された2区間の予定長を確認し、`Enter`で分割します。

分割後の両区間はそれぞれ3 mを超える必要があります。有効な分割位置を持たない全長6 m以下のレールは赤く表示され、選択できません。

Enterを押した時にレールを持っていればそのモデルを使い、持っていなければ分割元モデルを引き継ぎます。

## レール移動ツール

### 概要

既設レールの端点を任意位置へ移動するほか、レール中央を選択して線形全体を平行移動します。複数の論理レールを選択してまとめて平行移動できます。

### 端点移動

1. レール端点の候補マーカーを右クリックします。同じ位置で接続している端点はまとめて選択されます。
2. 移動先へ視線を向けて右クリックし、位置を固定します。
3. `Enter`で移動・再生成します。

### 平行移動

1. レール中央を右クリックして選択します。2本目以降は、すでに選択したレールへ端点で接続しているレールだけを追加できます。選択済みレールを右クリックすると解除します。
2. 移動先側へ視線を向けます。全選択レールへ同じ平行距離のプレビューが表示されます。
3. レールから外れた空間を右クリックして位置を固定します。
4. `Enter`でまとめて移動・再生成します。

| 操作 | 動作                |
| ---- | ------------------- |
| `P`  | 0.1 mスナップON/OFF |

移動元の前後に接続されたレールがある場合は、接続端点も連動して移動します。移動先付近に別のレール端点がある場合は、その端点への接続を優先します。

## カント整形ツール

通常レールの端点を右クリックで複数選択し、`Enter`で設計速度に応じた均衡カントを一括適用します。`↑` / `↓`で設計速度を1 km/hずつ変更し、`Ctrl+←` / `Ctrl+→`で1067 mm、1372 mm、1435 mm（在来線）、1435 mm（新幹線）、1000 mm（モノレール）を切り替えます。速度変更はチャットへ出さず、画面上の数字で確認します。今回はカント不足を考慮しません。

## 分岐生成ツール

既設レール上の分割点を右クリックした後、自由点または別レール端点を右クリックし、`Enter`で単純分岐を生成します。レール生成Aと同じ`P` / `Ctrl+P`のスナップ、`O`と矢印キーの曲線半径固定を使用できます。手持ちレールがあればそのモデル、なければ分割元モデルを使います。勾配・縦曲線のあるレールと既存分岐は選択できません。

## 制限事項

- レール生成・分割・移動・カント整形・分岐生成のワールド変更機能はKaizPatchX向けです。
- 分岐器は線路分割・レール移動の対象外です。
- 列車が在線しているレールは安全のため変更できません。
- 未ロードチャンクに物理コアがある自動分割レールは変更できない場合があります。
- 見た目上レールが接していても、道床所有状態や端点条件によって列車が遷移できない場合があります。
- Undoでレールは復元されても、生成時に破壊された通常ブロックなどは復元されません。
