# 線路分割ツール

既設レールを指定位置で2本に分割します。通常レール・自動分割レールのほか、4点マーカー構成の片渡り分岐とシーサスクロッシングを分割できます。

## 使い方

1. 分割するレールへ視線を合わせます。
2. 黄色の強調表示と分割候補のマーカーを確認し、右クリックで確定します。
3. 分割後の予定長を確認します。モデルを変更する場合は、使用する大型レールアイテムを持ちます。
4. `Enter`で分割します。

## 操作

| 操作       | 動作                     |
| ---------- | ------------------------ |
| 右クリック | 分割対象と位置を確定     |
| 左クリック | 確定を解除して1段階戻る  |
| Enter      | 確定した位置で分割       |
| Ctrl+Z     | 直前の分割を取り消す     |
| H          | ヘルプを表示             |
| Q          | ツールを終了             |
| Tab長押し  | ツール切替ホイールを開く |

## 設定と動作

### 通常レールの分割

通常レールは約0.5 m間隔の描画位置に合わせて分割候補を表示します。視線先のレール全体を黄色で強調し、最寄りの候補へマーカーを表示します。分割できない長さのレールは赤色になります。

右クリックで確定すると水色になり、分割後の2本の予定長を各区間の中間へ0.01 m単位で表示します。画面右上にも分割前後の予定長を表示します。両区間が64 m以下の場合はそれぞれ1本の通常レールになり、長い区間は自動分割されます。

### 渡り線分岐の分割

分岐器全体を黄色で強調し、分割位置を固定マーカーで示します。カーソルを動かしても分割位置は変わりません。選択後は水色、選択済みの分岐器へ視線を合わせると暗い水色になります。

| 対象                 | 分割結果と表示                                                                                                                |
| -------------------- | ----------------------------------------------------------------------------------------------------------------------------- |
| 4点片渡り分岐        | 本線2本と渡り線の中央にマーカーを表示。3点分岐レール2本と通常レール2本へ分割し、画面右上には本線それぞれの半長を表示          |
| シーサスクロッシング | 本線・斜線をおよそ3等分する8か所にマーカーを表示。3点分岐レール4本と通常レール4本へ分割し、画面右上には中央本線の予定長を表示 |

渡り線分岐を分割してできる通常レールは自動分割しません。シーサスの中央は、平行な本線2本と交差する直線2本になります。走行できる接続を優先するため、側線の形状や接線を調整する場合があります。曲線片渡りでは本線の曲線と分割点の接線を維持しますが、渡り線側の曲がり方が調整される場合があります。

### モデルと取り消し

`Enter`時に大型レールアイテムを持っていれば、そのモデルと設定を分割後のレールへ適用します。持っていなければ分割元を引き継ぎます。

`Ctrl+Z`で分割前のレールへ戻し、元の形状・モデル・信号・サブレールを復元します。4点分岐器の分割も、このツールの`Ctrl+Z`で元へ戻せます。

## 制限

- 通常レールは、分割後の両区間がそれぞれ3 mを超える必要があります。全長6 m以下は分割できません。
- 渡り線分岐は水平な4点構成が対象です。シーサスの本線は20 m以上が必要です。
- 3点分岐とダイヤモンドクロッシングは対象外です。対応外の4点分岐は強調表示だけを行い、選択できません。
- 通常レール部分が生成距離の上限を超える場合や、コア・道床を安全に配置できない場合は、元の分岐器を変更せず中止します。既設の接続先コアは保護します。
- 列車が乗っているレールは変更できません。
- 縦曲線やランダムカントを含むレールでは、分割前と完全に同じ形状になる保証はありません。
- 撤去と再生成を伴うため、使用前にワールドをバックアップしてください。
- Undoは直前の1操作が対象です。ツール終了・スクリプト再読み込み・サーバー再起動後には使えません。
