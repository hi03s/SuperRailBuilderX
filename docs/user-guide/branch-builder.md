# 分岐生成

既設レールを組み替えて、本線と側線を持つ単純分岐を生成します。

## 使い方

1. 元になる既設レールの線路部分、または端点を右クリックします。線路部分には約0.5m間隔の分割候補、端部には正確な端点を表示します。
2. 自由点、または別レールの未接続端点を右クリックして側線の終点を選びます。
3. プレビューを確認し、Enterで生成します。

線路部分から始めると、元レールを分割し、その半区間と新線を分岐へ組み替えます。端点から始めると、選択端点を根元、元レールの反対端を本線、新しい終点を側線とする分岐へ組み替えます。始点側は接続済み端点も選べます。同じ接続点に複数のレールがある場合は、展開方向に合う元レールを使います。

## 操作

| 操作            | 動作                                                       |
| --------------- | ---------------------------------------------------------- |
| 右クリック      | 元レール・側線の終点を順に選択                             |
| 左クリック      | 選択を1段階戻す                                            |
| Enter           | プレビューの分岐を生成                                     |
| P               | スナップをOFF→距離→ブロックの順に切り替え                  |
| Ctrl+P          | 距離スナップの角度を切り替え                               |
| O               | 曲線半径固定をON/OFF                                       |
| ← / →           | 半径を1mずつ変更                                           |
| Ctrl+← / Ctrl+→ | 半径を100mずつ変更                                         |
| Ctrl+Z          | 直前に生成した分岐を撤去し、元レールと変更したカントを復元 |
| H               | ヘルプを表示                                               |
| Tab長押し       | ツール切り替えホイールを開く                               |
| Q               | ツールを終了                                               |

チャット欄を開いてスクロールするとヘルプ全文を確認できます。

## 設定と動作

### 終点とスナップ

自由終点はカーソルのXZ座標と元レールの高さで決まります。異なる高さのブロックを指しても、分岐は水平に展開します。既設レールの未接続端を指すと、その正確な端点へ接続します。接続済み端点は終点候補に含めません。

距離・ブロックスナップでは、自由終点のXZ座標をワールド基準の0.5m格子へ合わせます。高さは元レールに揃え、接続先の既設端点は移動しません。固定半径による線形の調整はスナップの後に適用します。

### 半径と表示

半径キーは長押しに対応します。初期単位で40回変更すると、通常は1→10mへ加速します。Ctrl併用時は100m単位のままです。キーを離す・方向を変える・Ctrlを切り替えると初期単位へ戻ります。

画面にはスナップ、曲線半径、レール長を表示します。ブロックスナップ中は「ブロック」を表示します。

### モデルとカント

生成時にレールアイテムを持っていれば、そのモデルを分岐に使います。持っていなければ元レールのモデルを使います。分割後に残る通常レールは元のモデルを保持します。

元レールと生成する分岐のカントは0になります。元レールや新線の接続先にある既設レールも、接続端点のカントを0に揃えます。Ctrl+Zでは変更した既設レールのカントを生成前へ戻します。

## 制限

使用前にワールドをバックアップしてください。元レールには、水平で在線していない通常レールを使います。分岐レール、自動分割状態が不正なレール、勾配・縦曲線のあるレールは選べません。

- 中央で分割する場合、分割後の両区間は3mを超える必要があります。全長6m以下のレールは端点からのみ使用できます。終点側は通常レールまたは分岐レールの、水平な未接続端部へ接続できます。分岐レールの3つ目以降の端部も選択できます。

- 道床の配置では通常ブロックを置換する場合があります。既設コアを保護し、安全な配置ができなければ生成を停止します。Undoでは生成した分岐と残りの通常半区間を撤去し、元レールを復元します。
