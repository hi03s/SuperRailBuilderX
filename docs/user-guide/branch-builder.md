# 分岐生成ツール

既設レールを組み替えて、本線と側線を持つ単純分岐を生成します。KaizPatchX / AppleExtendedに対応します。使用前にワールドをバックアップしてください。

## 操作と生成方式

1. 既設レールの中央ではレール分割ツールと同じ約0.5 m間隔の候補、端部では正確なRailPositionを右クリックする。始点側は接続済み端点も選択でき、同じ接続点の複数レールから展開方向に合う元線路を選ぶ。中央分割後の両区間は3 m超とする。
2. レール生成Aと同様に自由点または別レール端点を右クリックし、選択点からの理論RailMapを決める。
3. `Enter`で、中央選択時は元レールを分割して新線側の半区間と新線を単純分岐へ合成する。端部選択時は選択端点を根元、元レールの反対端を本線、新しい終点を側線とする単純分岐へ元レールを組み替える。

自由終点はカーソルのXZ座標と選択元レールの高さで決まる。異なる高さのブロックを指しても水平に展開する。既設の未接続端を指すと正確な端点へ接続する。すでに別レールと接続済みの端点は終点候補に含めない。

`P`でOFF→距離→ブロックの順にスナップを切り替える。レール生成Aで既設レールを始点にした場合と同様、距離・ブロックスナップでは自由終点のXZ座標をワールド基準0.5 mへ丸める。分岐は水平限定のため高さは選択元レールに揃える。既設接続端は維持する。GUIはレール生成Aと同じグリッド・カーブ・レール長の3行で、ブロック中は「ブロック」を表示する。

`O`で曲線半径固定、`←` / `→`で1 m、`Ctrl+←` / `Ctrl+→`で100 mずつ半径を変更する。長押しで初期単位の40回分を変更すると、通常は10 mへ加速し、それ以上の桁には上がらない。Ctrl併用時は長押ししても100 m単位のままとする。キーを離すか方向・Ctrl状態を変えると初期単位に戻る。固定半径による線形整形はスナップの後に従来どおり適用する。左クリックは1段階戻る。`Ctrl+Z`は生成した分岐と通常半区間を撤去し、中央・端点選択とも元レールを復元する。ヘルプは1行1キーで、最終行にチャットスクロールの案内を表示する。

Enter時にレールを持っていればそのモデルを分岐へ使い、持っていなければ分割元モデルを使う。残る通常半区間は分割元モデルを保持する。道床はレール移動・builder1と同じ列挙、既設コア保護、所有更新規則を使う。

生成時はベースレールのカントを全端点で0にし、分岐化の前後に検出した接続レールの接続端点、新線の接続先端点、生成物も0に揃える。`Ctrl+Z`では変更した既設レールのカントを生成前へ戻す。

元線路として分岐レール、自動分割状態が不正なレール、在線中のレール、勾配または縦曲線を持つレールは選択できない。全長6 m以下は中央分割できないが、端点起点には使用できる。終点側の接続先は通常レールまたは分岐レールの水平な未接続端部に限る。分岐レールは3つ目以降の端部も候補に含める。

## 開発者向け実装情報

サーバーは対象キー、分割比、端点、水平性、在線状態を再検証します。

単純分岐で共用される根元RailPositionは、分割元半区間の接線とアンカー長を保持する。新線プレビュー用のアンカー長で本線側を上書きせず、短い本線側で曲線が中央付近まで過伸長することを防ぐ。曲線半径パネルはアルファブレンドを有効化し、透明部分を黒く表示しない。

KaizPatchX / AppleExtended同梱の`LibRenderRail.js`は、自由配置された分岐根元の水平オフセットを外側の描画変換と`renderRailMapDynamic`内で二重加算する。このためRailMapと台車追従が正しくても、分岐の根元から中央までだけ描画がずれる。SRBXはレールパック自体を変更せず、builder1の`init()`を起点にモデル構築完了を待ち、各レール描画ScriptEngineの`renderRailDynamic2`へruntime compatibility patchを一度だけ適用する。補正は分岐可動部を描く`renderRailMapDynamic`の実行中だけに限定し、中央から終端側の`renderRailMapStatic`には適用しない。通常RTM 1.7.10 / 1.12.2ではこのpatchを起動しない。
