# カント整形ツール

選択したレールの両端へ、設計速度と軌間に応じたカントを一括設定します。

## 使い方

1. `↑` / `↓`で設計速度、`Ctrl+←` / `Ctrl+→`でレール種類を設定します。
2. 対象レールを右クリックして選択します。複数選択でき、選択済みレールを右クリックすると解除します。
3. 両端に表示されるカント高さと、変更の影響を受ける接続レールを確認します。
4. `Enter`で一括適用します。

## 操作

| 操作            | 動作                                          |
| --------------- | --------------------------------------------- |
| 右クリック      | レールを選択・解除                            |
| 左クリック      | 直前の選択を1段階戻す                         |
| ↑ / ↓           | 設計速度を1 km/hずつ増加・減少（長押し対応）  |
| Ctrl+↑ / Ctrl+↓ | 設計速度を50 km/hずつ増加・減少（長押し対応） |
| Ctrl+← / Ctrl+→ | レール種類を切り替える                        |
| Enter           | 選択レールの両端へカントを一括適用            |
| Ctrl+Z          | 直前の一括適用を取り消す                      |
| H               | ヘルプを表示                                  |
| Q               | ツールを終了                                  |
| Tab長押し       | ツール切替ホイールを開く                      |

## 設定と動作

### 設計速度とレール種類

設計速度の初期値は100 km/h、設定範囲は0〜999 km/hです。画面右側で現在の速度とレール種類を確認できます。レール種類を変えると、軌間と最大カントをチャットにも表示します。初期種類は1067 mmです。

| レール種類            | 最大カント |
| --------------------- | ---------: |
| 1067 mm               |     105 mm |
| 1372 mm               |     150 mm |
| 1435 mm（在来線）     |     150 mm |
| 1435 mm（新幹線）     |     200 mm |
| 1000 mm（モノレール） |     110 mm |

均衡カント高さは`軌間(mm) × 速度(km/h)^2 ÷ (127 × 曲線半径(m))`で計算し、種類ごとの最大値で制限します。カント不足は加えません。曲線半径は各端付近の線形から個別に求めるため、両端の値が異なることがあります。直線と設計速度0 km/hでは0 mmになります。0 km/hから速度を上げても、曲線に応じたカントの向きを保ちます。

### 選択表示と接続レール

通常レール・自動分割レールを、分割セクションごとではなく1本のレール全体として選択します。選択レールは水色、両端に接続して変更の影響を受ける未選択レールは黄緑色で強調します。視線先の未選択レールは黄色、選択済みレールは解除対象を示す暗い水色になります。

選択レールの両端には、計算後のカント高さをmm単位で表示します。同じ位置で接続するレールの端部にも、向きに合わせてカントを適用します。`Ctrl+Z`では接続相手を含む全変更を戻します。Undoに失敗した場合も履歴を保持し、再試行できます。

## 制限

- 分岐レールと列車が乗っているレールは変更できません。
- レールを分割する機能や、レール中央だけへカントを適用する機能はありません。
- 未選択の接続レールも変更されます。使用前にワールドをバックアップしてください。
- Undoは直前の1操作が対象です。ツール終了・スクリプト再読み込み・サーバー再起動後には使えません。
