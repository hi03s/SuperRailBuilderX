# カント整形ツール

選択した理論レールの両端へ設計速度に応じたカントを設定します。KaizPatchX / AppleExtendedに対応します。

## 操作

- `↑` / `↓`: 設計速度を1 km/hずつ変更する。初期値100 km/h、範囲0〜999 km/h。長押し対応。速度は状態GUIだけに表示し、カーソル先には速度の数字を表示しない。
- `Ctrl+↑` / `Ctrl+↓`: 設計速度を50 km/hずつ変更する。長押し対応。0 km/hでは選択レールの両端を水平にする。
- `Ctrl+←` / `Ctrl+→`: レール種類を切り替え、軌間と最大カントをチャット表示する。初期値は1067 mm。
- 右クリック: 通常・自動分割レールを論理RailMap単位で複数選択/解除する。同じレールのどこを指しても同じ選択になり、選択されたレールの両端へ計算後のカント高さを`cantPanel`でmm表示する。
- 左クリック: 最後の選択を1段階戻す。
- `Enter`: 選択レールの両端へカントを一括適用する。
- `Ctrl+Z`: 直前の一括適用を取り消す。

選択レールは水色、両端に接続して変更の影響を受ける未選択レールは黄緑色（99ff00）で強調する。未選択レールのホバーは黄色を優先し、選択済みレールのホバーは解除を示す暗い水色（009999、線路移動と同じ）にする。同じ論理レールを重複描画せず、レールを指す選択カーソルは表示しない。両端のカントmmパネルは維持する。レールの分割や中央だけへの適用は行わない。同じ端点位置へ接続するレールも向きに応じた符号で同時適用し、`Ctrl+Z`で接続相手を含む全変更を戻す。Undo失敗時は履歴を残して再試行できる。

## 計算とレール種類

均衡カント高さは `軌間(mm) × 速度(km/h)^2 ÷ (127 × 曲線半径(m))` とし、カント不足は加えない。曲線半径は選択レールの各端付近のRailMap接線変化から個別に求める。直線と速度0は0 mm。曲線方向を独立して保持し、速度0から増速してもカントの符号を保つ。高さからRTMの角度へはSRB3と同じ `asin(高さ / 軌間)` を使う。

| 種類                 | 最大カント |
| -------------------- | ---------: |
| 1067 mm              |     105 mm |
| 1372 mm              |     150 mm |
| 1435 mm (在来線)     |     150 mm |
| 1435 mm (新幹線)     |     200 mm |
| 1000 mm (モノレール) |     110 mm |

## 制限

分岐レールと列車が乗っているレールは変更できません。選択されていない接続レールも影響を受けるため、使用前にワールドをバックアップしてください。Undo履歴はツール終了・スクリプト再読み込み・サーバー再起動後には使えません。

## 開発者向け実装情報

最大値はSRB3の実装を基準とし、1435 mm在来線だけを150 mmとして追加した。サーバーは各レールの両端の組を検証し、旧分割/中央リクエストや重複/片端のみのリクエストを拒否する。互換層で対象キー、端点座標、角度、在線状態を再検証する。KaizPatch/AEに対応し、非対応ターゲットは安全に停止する。
