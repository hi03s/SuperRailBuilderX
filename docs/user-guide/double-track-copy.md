# 複線コピーツール

既設の通常レールを理論レール単位で複数選択し、カーソルを伸ばした側へ指定間隔で複製します。KaizPatchX / AppleExtendedに対応し、分岐レールは選択対象外です。

## 操作

| 操作                       | 動作                                                            |
| -------------------------- | --------------------------------------------------------------- |
| レールへカーソルを合わせる | 対象の論理RailMap全体を黄色で強調                               |
| レールを右クリック         | 対象を選択。選択済みなら選択解除                                |
| 空間を右クリック           | 現在の側・複製本数・生成プレビューを固定                        |
| 左クリック                 | 固定中は位置確定を解除。それ以外は最後の選択操作を1段階取り消す |
| `←` / `→`                  | 複製間隔を0.1 mずつ減少/増加。長押し対応。変更値をGUIへ表示     |
| `C`                        | 選択・選択履歴・向き・間隔を初期化。間隔は4.0 mへ戻る           |
| `Enter`                    | 右クリックで固定したプレビューのレールを一括生成                |
| `Ctrl+Z`                   | 直前に一括生成したレールをUndo                                  |
| `H`                        | ヘルプ表示                                                      |
| `Q`                        | ツール終了                                                      |

間隔の下限は0.1 mです。選択済みレールへ視線を合わせると、選択解除対象であることを示すため水色の強調表示が少し暗くなります。生成成功後は選択と選択履歴だけを解除し、間隔を維持します。生成後に別のレールを選択していても、Ctrl+Zで生成を撤去すると現在の選択を解除し、その生成に使った選択状態へ戻します。

## 複製範囲

最初に選択したレールの中点と接線を基準に、視線先がある側を複製方向とします。基準から視線先までの水平法線距離を `D`、間隔を `S` としたとき、複製列数は `floor(abs(D) / S)` です。各列は `S`、`2S`、`3S` … の位置に生成されます。

選択した全レールを各列へ複製します。理論長が2 m以下になった個別レールはプレビューにも生成要求にも含めません。

曲線内側へ複製するときは、元レールの始終端を結ぶ弦と複製後の弦の内積を比較し、複製後の弦がほぼ消失または反転する手前で、その列以降のプレビューと生成を打ち切ります。曲率中心を越えて線形が反転し、元レール側へ戻って既設・生成済みレールと重なる状態は生成しません。複数選択では、いずれか1本がこの制限へ達した列から全体を打ち切ります。

## モデルの選択とUndo

- Enter時に大型レールアイテムを持っている場合は、そのRailPropertyを全生成レールへ適用します。
- 持っていない場合は、各複製元レールのRailPropertyを複製して使います。
- 生成RailPropertyは長距離でも安全に生成できるよう`autoSplit`を有効にします。
- 一括生成の途中で失敗した場合は、その要求内ですでに生成したレールを逆順にロールバックします。
- Undoは直前の一括生成記録を逆順に撤去し、生成時の選択状態を復元します。複製元レールは変更しません。
- Undoで復元した選択には選択履歴も再構成するため、その直後から左クリックで最後の選択を解除できます。

## 接続と制限

複製先の端点から0.5m以内に、コピー元以外の接続可能な通常レール端点がある場合、その端点への接続を試みます。選択したレール同士の接続も維持します。列車が乗っているレールは変更できません。

生成途中で失敗した場合は、同じ操作で生成したレールを撤去します。通常ブロックの置換はUndoで復元されません。使用前にワールドをバックアップしてください。

## 開発者向け実装情報

### 平行線形の計算

各RailMapの両端について、始端は始端接線、終端は終端接線を進行方向へ反転した接線を使い、その水平法線方向へ端点を移動します。Y座標は変更しません。

元の水平弦長を `L`、移動後の水平弦長を `L'` とし、始終端の水平・垂直アンカー長へ `L' / L` を掛けます。したがって元レールを単純平行移動するのではなく、同じ端点角度から新しいRailMapを構成します。カーブ内側は短く、外側は長くなり、アンカー長も曲率側に合わせて増減します。カント値は複製元から引き継ぎます。

### 接続

- 計算した端点から半径0.5 m以内に、選択中の複製元以外の接続可能な通常レール端点がある場合、その端点の座標・反転方向・反転角度を使用します。
- 同じ複製列内で選択レール同士の端点が一致する場合は、2本のRailPosition所有ブロックを`RailPosition.REVISION`に従う接続対として割り当てます。
- サーバーは生成直前に、複製元の論理レールキーと両端座標を再検証します。

### クライアント同期

- 成功応答はクライアント要求1回につき一度だけ処理し、遅延同期した同じ応答でUndo用の選択記録を上書きしません。Undo後は撤去した論理レールキーを選択・端点吸着の対象外にし、該当するクライアント側論理レールを明示的に破棄してから、撤去対象経路のブロック更新を待ちます。

通常RTMの`mc1710`と`mc1122`では共通UIを生成しますが、ワールド生成処理は安全に停止します。
