# 複線コピーツール

既設レールを複数選択し、線形に沿った平行レールを指定間隔で複製します。

## 使い方

1. コピー元のレールを右クリックして選択します。複数のレールを選択できます。選択済みのレールを右クリックすると解除します。
2. `←` / `→`で複線間隔を調整します。
3. 生成する側へ視線を向け、プレビューで本数と線形を確認します。
4. 空間を右クリックして位置と本数を確定し、`Enter`で一括生成します。

## 操作

| 操作               | 動作                                              |
| ------------------ | ------------------------------------------------- |
| レールを右クリック | コピー元を選択・解除                              |
| 空間を右クリック   | 複製する側・本数・プレビューを確定                |
| 左クリック         | 位置の確定を解除、または直前の選択操作を1段階戻す |
| ← / →              | 複製間隔を0.1 mずつ減少・増加（長押し対応）       |
| Enter              | 確定したプレビューを一括生成                      |
| Ctrl+Z             | 直前の一括生成を取り消す                          |
| C                  | 選択・履歴・向き・間隔を初期化                    |
| H                  | ヘルプを表示                                      |
| Q                  | ツールを終了                                      |
| Tab長押し          | ツール切替ホイールを開く                          |

## 設定と動作

### 間隔と複製範囲

初期間隔は4.0 m、下限は0.1 mです。現在の値は画面右側に表示されます。最初に選択したレールの中点と向きを基準に、視線先がある側へ複製します。間隔を`S`、基準から視線先までの横方向の水平距離を`D`とすると、生成する列数は`floor(abs(D) / S)`です。各列へ選択した全レールを複製します。

接続している選択レールは、始点同士・終点同士の接続でも同じ側へ展開します。離れた選択群では、それぞれ最初に選択したレールの向きを基準とします。カーブ内側は短く、外側は長くなり、高さとカントは元レールを引き継ぎます。

### モデルと接続

`Enter`時に大型レールアイテムを持っていれば、そのモデルと設定を全生成レールへ適用します。持っていなければ、それぞれのコピー元を引き継ぎます。長いレールは自動分割されます。

複製先端点の0.5 m以内にコピー元以外の接続可能な通常レール端点がある場合、その端点への接続を試みます。選択レール同士の接続も維持します。接続時もコピー元のカントを保ち、接続先のカントは変更しません。

### 選択表示と取り消し

視線先の未選択レールは黄色、選択済みレールは水色で強調します。選択済みレールへ視線を合わせると、解除対象であることを暗い水色で示します。

生成成功後は選択と選択履歴を解除し、間隔を維持します。`Ctrl+Z`は生成レールを撤去して、生成時の選択と選択履歴を復元します。生成後に別のレールを選択していた場合も、その選択を置き換えます。コピー元は変更しません。一括生成が途中で失敗した場合は、その操作で生成済みのレールを撤去します。

## 制限

- 分岐レールは選択できません。列車が乗っているレールは変更できません。
- 複製後の長さが2 m以下になるレールは生成しません。
- 曲線内側へ寄せすぎて線形がつぶれたり反転したりする手前で、それ以降の列を生成しません。複数選択では1本でも制限に達した列から全体を打ち切ります。
- 使用前にワールドをバックアップしてください。生成時に置換した通常ブロックはUndoで復元されません。
- Undoは直前の1操作が対象です。ツール終了・スクリプト再読み込み・サーバー再起動後には使えません。
