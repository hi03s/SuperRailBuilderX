# ツール状態GUI

全ツールで画面上端の中央に枠付きツール名、左側に枠付きの現在時刻、右上に大アイコンを表示する。時刻はPCのローカル時刻を24時間表記の`HH:mm`で表示する。タイトルと時刻、状態文字は影付き白文字。状態行は大アイコンの下、右端の16 px列へ上から順に配置し、文字右端をアイコンの左4 pxにそろえる。Minecraftの別画面を開いている間は表示しない。操作中プレイヤーだけが表示対象です。

| ツール      | 上から並ぶ状態行                         | 表示条件・更新元                                                                                                                                                                                                                                          |
| ----------- | ---------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| レール生成A | グリッド、カーブ、レール長、勾配、縦曲線 | 距離の角度/ブロック、固定またはプレビュー半径、選択中のプレビュー長、目標勾配‰、縦曲線半径m                                                                                                                                                               |
| レール生成B | Aと同じ                                  | 半径は情報背景で直線またはL/Rを表示。レール長は設定長を常時表示。他はAと同じ                                                                                                                                                                              |
| 線路分割    | レール長を2行                            | 分割候補カーソルが表示されるホバー中、または分割点選択後に前後区間の予想長を小数2桁mで表示。対象なし/無効な候補は空欄                                                                                                                                     |
| 線路移動    | グリッド                                 | 0.1 mスナップのON/OFF背景のみ。文字なし                                                                                                                                                                                                                   |
| 複線コピー  | レール                                   | `間隔:4.0m`のように現在の間隔を小数1桁で常時表示。間隔変更/リセット時はチャットへ出力しない                                                                                                                                                               |
| カント整形  | 速度、レール                             | `設計速度:100km/h`、`種類:1067mm`などを常時表示。速度は0〜999 km/hで、カーソル先には表示しない。種類は在来線/新幹線などの区別も含む。種類変更時の最大カント付きチャット出力は維持                                                                         |
| 分岐生成    | グリッド、カーブ、レール長               | レール生成Aと同様にOFF/距離/ブロックを切替。距離では角度、ブロックでは`ブロック`を表示。固定ONなら設定半径、固定OFFで分岐候補があれば現在のプレビュー半径。無限大は`直線`。起点選択後に新線側プレビューの3D長を小数2桁mで表示。終点候補がない場合は0.00 m |

分岐の表示長は新線側だけの概算で、元レール側の残存区間は含みません。ツール切り替えは[TABホイール](tool-wheel.md)を参照してください。

## 開発者向け実装情報

`gui_base.png`は16×16グリッド。背景は(3,0)=OFF、(3,1)=ON、(3,2)=情報表示。状態アイコンは背景の上に重ねる。上部の文字表示枠は(0,2)、(1,2)、(1,2)、(2,2)の4タイルを横に並べる。

描画pass=0・material=0で1回描画します。分割長は既存論理RailMapの長さと分割比率から、分岐長は描画済み48分割の3D折線から求めます。GUIのためにRailMapを新規生成したりワールドへ書き込んだりしません。

共通実装は`src/common/assets/minecraft/scripts/superrailbuilderx/SRBXToolGui.ts`。霧隔離、行列・属性の個別保存/復元、1.12.2のGlStateManagerキャッシュ同期を行います。GLのPush/Popを使わず、旧Java 8u51のtry/finally内continue問題も回避する。異常時は`[SuperRailBuilderX GUI] tool=...`とstage/errorを記録してGUIを停止する。
