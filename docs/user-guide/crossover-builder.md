# 渡り線生成

水平な基準線と複線間隔から、片渡り分岐器またはシーサスクロッシングを生成します。

## 使い方

1. 未接続のレール端部、ブロック上の自由始点、または水平な既設通常レールの線路部分を右クリックします。
2. プレビューを確認し、形状と複線間隔を調整します。
3. Enterで生成します。生成後のUndoはできません。プレビューを十分に確認してから適用してください。

## 操作

| 操作            | 動作                                               |
| --------------- | -------------------------------------------------- |
| 右クリック      | 基準線を選択                                       |
| 左クリック      | 選択を解除                                         |
| C               | 選択・長さ・半径・間隔・始点高さなどを初期値に戻す |
| Enter           | 生成                                               |
| O               | 6種類の形状を順に切り替え                          |
| ↑ / ↓           | 複線間隔を±0.1m変更                                |
| Ctrl+↑ / Ctrl+↓ | 複線間隔を±1m変更                                  |
| ← / →           | 基準線のL/R半径を変更                              |
| Ctrl+← / Ctrl+→ | 半径を100m単位で変更                               |
| J / L           | 基準線の長さを減少 / 増加                          |
| Ctrl+J / Ctrl+L | 長さを10m単位から変更                              |
| P               | スナップOFF→距離→ブロック                          |
| Ctrl+P          | 角度スナップを切り替え                             |
| I / K           | 自由始点の高さを±1/16m変更                         |
| Ctrl+I / Ctrl+K | 自由始点の高さを±1m変更                            |
| Ctrl+C          | 設定をリセット                                     |
| H               | ヘルプ                                             |
| Tab長押し       | ツール切り替えホイールを開く                       |
| Q               | 終了                                               |

チャット欄を開いてスクロールするとヘルプ全文を確認できます。

## 設定と動作

### 形状

形状は「右片渡り（右複線）→左片渡り（右複線）→シーサス（右複線）→右片渡り（左複線）→左片渡り（左複線）→シーサス（左複線）」の順です。左右は基準線の始点から終点へ向かう方向で判断します。

自由始点・未接続端部では、レール生成Bと同じく設定長と半径から基準線を作ります。自由始点の方向はプレイヤーの向きを使います。初期長60m、初期半径は直線、初期複線間隔は4.0mです。Cリセットでもこの値へ戻ります。

片渡り4形状は、本線2本と渡り線の中央で分かれた「3点分岐レール2本＋通常レール2本」として生成します。通常レールのコアは外側端部に配置します。シーサス2形状は、全体をおよそ3等分した「3点分岐レール4本＋通常レール4本」として生成します。中央の交差部分は通常レール2本を重ねます。線路分割ツールでも同じ構成へ分割できます。シーサスは形状の完全な再現より走行できる構成を優先します。

曲線の片渡りは本線の形状と渡り線中央の位置・接線を維持しますが、3点分岐の制約に合わせて渡り線側の曲がり方を調整する場合があります。通常レール部分は自動分割せず、設定された通常レールの生成距離上限を超える場合やコア配置を確保できない場合は生成を中止します。

接続先のコアと重なる場合は、端点の座標・接線を保ったまま、新設コアの位置を同じ高さの敷設範囲内で調整します。安全な配置ができなければ元レールを変更せずに中止します。

### 基準線とモデル

新規の基準線では手持ちのレールモデルを使い、手に持っていない場合は接続先のモデルを使います。自由点だけで敷く場合はレールを手に持ってください。

選択可能な既設レールはホバー中に黄色、選択済みは水色、選択済みレールのホバー中は暗い水色で強調します。

既設レールの線路部分を選ぶと、その理論レール全体を基準線として置き換えます。元の長さ・曲線形状・モデルを維持し、長さと半径の操作は無効になります。既設の分岐レールと勾配のあるレールは基準線にできません。

### 接続と調整

複線側の端部は、付近の未接続で水平なレール端部へ吸着します。始点側のスナップはレール生成Bと共通です。分岐器のカントは0になります。接続する通常レールの端部カントも合わせます。

長さ・半径の長押し加速と、直線での一時停止は[レール生成B](builder2.md)と同じです。

## 制限

使用前にワールドをバックアップしてください。生成後のUndoはできません。

- 長さは30〜512m、複線間隔は0.1〜64mです。既設レールを基準線にする場合も30m以上が必要です。急曲線・狭すぎる間隔など、分岐器として成立しない形状やコア配置が競合する場合は生成できません。勾配設定と地上レール高延長はありません。
