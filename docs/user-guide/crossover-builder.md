# 渡り線生成

水平な基準線と複線間隔から、片渡り分岐器またはシーサスクロッシングを生成します。KaizPatch/AEと対応するSRBXPatchが必要です。モデル選択画面またはTABホイールから「渡り線生成」を選びます。

## 使い方

1. 未接続のレール端部、ブロック上の自由始点、または水平な既設通常レールの線路部分を右クリックします。
2. プレビューを確認し、形状と複線間隔を調整します。
3. Enterで生成します。Ctrl+Zで直前の生成を取り消します。

自由始点・未接続端部では、レール生成Bと同じく設定長と半径から基準線を作ります。自由始点の方向はプレイヤーの向きを使います。初期長40m、初期半径は直線、初期複線間隔は4.0mです。

新規の基準線では手持ちのレールモデルを使い、手に持っていない場合は接続先のモデルを使います。自由点だけで敷く場合はレールを手に持ってください。

選択可能な既設レールはホバー中に黄色、選択済みは水色、選択済みレールのホバー中は暗い水色で強調します。

既設レールの線路部分を選ぶと、その理論レール全体を基準線として置き換えます。元の長さ・曲線形状・モデルを維持し、長さと半径の操作は無効になります。既設の分岐レールと勾配のあるレールは基準線にできません。

複線側の端部は、付近の未接続で水平なレール端部へ吸着します。始点側のスナップはレール生成Bと共通です。分岐器のカントは0になります。接続する通常レールの端部カントも合わせ、Undoで元に戻します。

## 操作

| キー | 動作 |
| --- | --- |
| 右クリック | 基準線を選択 |
| 左クリック | 選択を解除 |
| C | 選択・長さ・半径・間隔・始点高さなどを初期値に戻す（Undoは維持） |
| Enter | 生成 |
| O | 6種類の形状を順に切り替え |
| ↑ / ↓ | 複線間隔を±0.1m変更 |
| Ctrl+↑ / Ctrl+↓ | 複線間隔を±1m変更 |
| ← / → | 基準線のL/R半径を変更 |
| Ctrl+← / Ctrl+→ | 半径を100m単位から変更 |
| J / L | 基準線の長さを減少 / 増加 |
| Ctrl+J / Ctrl+L | 長さを10m単位から変更 |
| P | スナップOFF→距離→ブロック |
| Ctrl+P | 角度スナップを切り替え |
| I / K | 自由始点の高さを±1/16m変更 |
| Ctrl+I / Ctrl+K | 自由始点の高さを±1m変更 |
| Ctrl+C | 設定をリセット |
| Ctrl+Z | Undo |
| H | ヘルプ |
| TAB長押し | ツール切り替え |
| Q | 終了 |

形状は「右片渡り（右複線）→左片渡り（右複線）→シーサス（右複線）→右片渡り（左複線）→左片渡り（左複線）→シーサス（左複線）」の順です。左右は基準線の始点から終点へ向かう方向で判断します。

長さ・半径の長押し加速と直線での一時停止はレール生成Bと同じです。長さは最大512m、間隔は0.1〜64mです。急曲線・狭すぎる間隔など、ネイティブ分岐器として成立しない形状やコア配置が競合する場合は生成できません。勾配設定と地上レール高延長はありません。

チャット欄を開いてスクロールするとヘルプ全文を確認できます。

## 開発者向け実装情報

クライアントは`render_builder1.ts`の専用モードと`SRBXCrossoverClient.ts`、形状計画は`SRBXCrossoverPlan.ts`、サーバー窓口は`server_crossover_builder.ts`です。

4端点の分岐マーカー属性をネイティブRailMakerへ渡し、片渡りは分岐2点・通常2点、シーサスは分岐4点として一つの分岐器を作ります。サーバーで水平・端点・既設基準線・在線・所有コアを再検証し、生成失敗時は元線形・モデル・信号・SubRail・接続カントを復元します。通常RTMターゲットでは生成を無効化します。
