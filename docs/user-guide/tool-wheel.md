# ツール切り替えホイール

全7ツールの操作中にTABを長押しすると、暗い背景の上に中央が空いたリングを表示する。内外の円と放射状の仕切りで7区画に分け、各区画へアイコンと名前を配置する。真上から時計回りに、レール生成A、レール生成B、線路分割、線路移動、複線コピー、カント整形、分岐生成を配置する。選択中の区画は背景色と黄色の名前で強調する。

- マウスを中心から選びたいツールの方向へ動かす。中央の「変更なし」エリアへ戻すと、現在使用中のツールが選ばれ、切り替えを取り消せる。
- ←/→でも反時計回り/時計回りに選べる。マウスを動かさなければキーで選んだ項目を維持する。
- TABを離すと選択したモデルへ切り替える。同じツールを選んだ場合は変更しない。
- 左クリックでも決定して閉じる。クリック座標から選択を更新するため、中央でクリックすると切り替えない。右クリックでは決定しない。
- ESCは切り替えをキャンセルする。クリック決定/ESCの後、TABを押し続けても再度開かず、一度離してから開く。

メニュー中はマウスカーソルを操作でき、通常ツールの入力とプレビューは停止します。ゲームを一時停止しない。切り替え後もボタン・矢印キーを離すまで入力を止め、押しっぱなしによる誤選択を防ぐ。

標準GUIを開く際のキー解除でTABのプレイヤーリスト入力を抑える構成。描画は標準の画面レイヤーなので、リストが残る環境でもリストより上に表示する。KaizPatch/AEの実マルチプレイでの非表示は未確認。キー設定を書き換えない。

## 開発者向け実装情報

専用GuiScreenを使ってマウスを解放します。切り替え後の入力待機状態は、新しいモデルのスクリプトにも共有します。モデル変更はサーバーで実行する。操作プレイヤーがツールの所有者であること、対象がSRBXの7モデルのいずれかで存在すること、生成/移動/Undoなどの処理要求が残っていないことを再検証する。処理要求が送信中ならメニューを開かず、サーバーでも競合する切り替えを拒否する。エンティティを置き換えず、切り替えたツールの処理を次Tickから使用する。ワールドのレールを書き換える操作は行わない。

描画にはSRBXToolGuiの行列/属性の個別保存・復元を利用し、GLのPush/Popは使わない。エラー時はメニューを閉じて無効化し、`[SuperRailBuilderX wheel]`または`[SuperRailBuilderX GUI]`へ診断を記録する。サーバーは切り替え結果を`[SuperRailBuilderX wheel] target=..., result=...`へ記録する。
