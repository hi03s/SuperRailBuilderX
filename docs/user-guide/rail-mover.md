# レール移動ツール

既設レールの端点を移動したり、レール全体を平行移動したりします。接続した複数のレールをまとめて平行移動できます。

## 使い方

### 端点を移動する

1. 移動するレール端点の候補マーカーを右クリックします。同じ位置で接続している端点はまとめて選択されます。
2. 移動先へ視線を向け、プレビューを確認します。
3. 右クリックで移動先を確定し、`Enter`で移動します。

### レール全体を平行移動する

1. レール中央を右クリックして選択します。2本目以降は、選択済みレールへ端点で接続しているレールを追加できます。選択済みレールを右クリックすると解除します。
2. 移動する側へ視線を向け、全選択レールのプレビューを確認します。
3. レールから外れた空間を右クリックして位置を確定します。レール上を移動先にする場合は`Ctrl+右クリック`で確定します。
4. `Enter`でまとめて移動します。

## 操作

| 操作                   | 動作                                            |
| ---------------------- | ----------------------------------------------- |
| 端点を右クリック       | 移動する端点を選択                              |
| レール中央を右クリック | 平行移動するレールを選択・解除                  |
| 移動先を右クリック     | 移動先を確定                                    |
| Ctrl+右クリック        | レールの選択を変更せず、平行移動先を確定        |
| 左クリック             | 移動先の確定を解除、または直前の選択を1段階戻す |
| P                      | 0.1 mスナップのON/OFFを切り替える               |
| Enter                  | 確定した移動を適用                              |
| Ctrl+Z                 | 直前の移動を取り消す                            |
| H                      | ヘルプを表示                                    |
| Q                      | ツールを終了                                    |
| Tab長押し              | ツール切替ホイールを開く                        |

## 設定と動作

### 移動先とスナップ

0.1 mスナップは初期状態ではOFFです。`P`で切り替えます。確定後に切り替えると、移動先の確定が解除されるため、再度確定してください。

平行移動では選択レールを同じ距離だけ移動します。移動元の前後へ接続されたレールがある場合は、その接続端点も連動して移動します。移動先付近に接続可能な別レール端点がある場合は、その端点への接続を優先します。

### 取り消し

`Ctrl+Z`で、このツールによる直前の移動を取り消します。移動に伴って変更した接続レールも対象になります。

## 制限

- 分岐器全体は平行移動できません。個々の端部を選択して移動することはでき、接続する通常レールも追随します。
- 列車が乗っているレールは変更できません。
- 未ロードのチャンクにコアがある自動分割レールは、変更できない場合があります。
- レールの撤去と再生成を伴います。接続相手も変更されるため、使用前にワールドをバックアップしてください。
- 見た目上接していても、端点や道床の状態によって列車が移行できない場合があります。
- Undoは直前の1操作が対象です。ツール終了・スクリプト再読み込み・サーバー再起動後には使えません。
