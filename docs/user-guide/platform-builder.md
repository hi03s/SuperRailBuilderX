# 組ホーム

選択した線路の右側または左側へ、手持ちのレールモデルを線形に沿って1列敷設します。プラットフォームモデルをレールアイテムとして持って使用します。

## 使い方

1. 組ホームツールへ切り替え、使用するレールアイテムを手に持ちます。
2. 基準のレールを右クリックして選択します。接続した複数のレールも選択できます。選択済みレールを右クリックすると解除します。
3. `←` / `→`で間隔、`↑` / `↓`で高さを調整します。
4. 線路の右または左へ視線を向け、プレビューで展開方向を確認します。
5. 空間を右クリックして方向を確定し、`Enter`で生成します。

## 操作

| 操作               | 動作                                              |
| ------------------ | ------------------------------------------------- |
| レールを右クリック | 基準レールを選択・解除                            |
| 空間を右クリック   | 展開方向を確定                                    |
| 左クリック         | 展開方向の確定を解除、または直前の選択を1段階戻す |
| ← / →              | 間隔を0.1 mずつ減少・増加                         |
| ↑ / ↓              | 高さを1/16 mずつ上げる・下げる                    |
| Enter              | 確定したプレビューを生成                          |
| Ctrl+Z             | 直前に生成したホームを撤去                        |
| C                  | 選択・間隔・高さを初期化                          |
| H                  | ヘルプを表示                                      |
| Q                  | ツールを終了                                      |
| Tab長押し          | ツール切替ホイールを開く                          |

## 設定と動作

初期間隔は2.0 m、初期高さは基準レールから1.5 m上です。現在の値は画面右側に表示されます。値を変更すると方向の確定が解除されるため、再度右クリックで確定してください。

基準線路の平面線形と勾配を引き継ぎ、ホームの横断面のカントは0にします。生成するモデルと設定には、手持ちのレールアイテムを使います。

`Ctrl+Z`は、このツールで直前に生成したホームを撤去します。

## 制限

- 手にレールアイテムがない場合は生成しません。
- 分岐レールは基準として選択できません。
- 2 m以下の線路や、内側へ寄せすぎて曲線が反転する位置には生成できません。
- 既設レールのコアと保護対象の道床は置換しません。生成距離の上限を超える場合や、安全に配置できない場合は生成できません。
- 使用前にワールドをバックアップしてください。生成時に置換した通常ブロックはUndoで復元されません。
- Undoは直前の1操作が対象です。ツール終了・スクリプト再読み込み・サーバー再起動後には使えません。
