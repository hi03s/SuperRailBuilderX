# 組ホーム

選択した線路の線形に沿って、右側または左側に手持ちのレールモデルを1列敷設します。プラットフォームモデルをレールアイテムとして持って使用してください。選択した線路のモデルをコピーする機能ではありません。

## 使用手順

1. 組ホームツールへ切り替え、使用するレールアイテムを手に持ちます。
2. 基準のレールを右クリックして選択します。接続した複数の理論レールも選択できます。選択済みレールを右クリックすると解除します。
3. カーソルを線路の右または左に向け、プレビューで展開方向を確認します。
4. 空間を右クリックして展開方向を確定し、Enterで生成します。

初期間隔は2.0m、初期高さは基準レールから1.5m上です。線路の勾配と平面線形を引き継ぎ、ホームの横断面のカントは0とします。

## 操作

| 操作 | 機能 |
| --- | --- |
| 右クリック | 基準レールを選択・解除 |
| 空間を右クリック | 展開方向を確定 |
| 左クリック | 展開方向の確定を解除、または直前の選択を戻す |
| → | 間隔を0.1m増やす |
| ← | 間隔を0.1m減らす |
| ↑ | 高さを1/16m上げる |
| ↓ | 高さを1/16m下げる |
| Enter | 生成 |
| Ctrl+Z | このツールで直前に生成したホームを撤去 |
| C | 選択と間隔・高さを初期化 |
| H | ヘルプ |
| Q | 終了 |
| TAB | ツール切替メニュー |

間隔と高さは画面右側に表示されます。値を変えると展開方向の確定が解除されるため、再度確定してください。チャット欄を開いてスクロールすると、ヘルプの全文を読めます。

## 制限

- KaizPatch/AEでは対応するSRBXPatchも導入してください。
- 分岐レールは基準として選択できません。
- 2m以下の線路や、内側へ寄せすぎて曲線が反転する位置には生成できません。
- 既設コアの保護や生成上限は、ほかの生成ツールと共通です。
- 手にレールアイテムがない場合は生成しません。

## 開発者向け

`render_platform_builder.ts`が選択・展開方向・プレビュー、`server_platform_builder.ts`が生成要求・Undoを処理します。`SRBXPlatformGeometry`の共通計算を両側で使用します。サーバーは理論レールのキーと端点を再検証して生成位置を再計算し、クライアントが送ったプレビュー座標を採用しません。

生成は`createBuilderRail`の手持ちモデル必須オプションを利用します。共通の既設道床・コア保護を経由し、Undoではこのツールが生成したレールの識別キーを確認して撤去します。
