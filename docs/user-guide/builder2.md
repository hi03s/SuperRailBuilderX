# レール生成B

半径・長さ・勾配を事前に設定し、始点だけを選んでレールを生成します。

## 使い方

1. 長さ・半径・目標勾配を設定します。
2. 既設レールの未接続端点、またはブロック上の自由始点を右クリックします。
3. プレビューを確認し、Enterで生成します。

自由始点では選択時のプレイヤーの向き、既設端点ではその接線方向へ生成します。自由始点から生成する場合はレールアイテムを持ってください。既設端点を使う場合は、手持ちのレールを優先し、持っていなければ接続先のモデルと設定を使います。

## 操作

| 操作            | 動作                                            |
| --------------- | ----------------------------------------------- |
| 右クリック      | 始点を選択                                      |
| 左クリック      | 始点の選択を解除                                |
| Enter           | プレビューのレールを生成                        |
| C               | 設定を維持して選択を解除                        |
| Ctrl+C          | 選択と設定を初期化                              |
| P               | スナップをOFF→距離→ブロックの順に切り替え       |
| Ctrl+P          | 距離スナップの角度を1°→5°→15°へ変更（初期値5°） |
| ← / →           | L側 / R側へ半径を1m単位で変更                   |
| Ctrl+← / Ctrl+→ | 半径を100m単位で変更                            |
| J / L           | 長さを0.1m減少 / 増加                           |
| Ctrl+J / Ctrl+L | 長さを10m単位で変更                             |
| ↑ / ↓           | 目標勾配を1‰ずつ変更                            |
| Ctrl+↑ / Ctrl+↓ | 縦曲線半径を1000mずつ変更                       |
| I / K           | 自由始点を選ぶ高さを±1/16m変更（選択前のみ）    |
| Ctrl+I / Ctrl+K | 自由始点を選ぶ高さを±1m変更（選択前のみ）       |
| U               | 条件を満たす0‰の自由端を地上レール高へ合わせる  |
| Ctrl+Z          | 直前の生成を取り消し、始点の選択へ戻る          |
| H               | ヘルプを表示                                    |
| Tab長押し       | ツール切り替えホイールを開く                    |
| Q               | ツールを終了                                    |

チャット欄を開いてスクロールするとヘルプ全文を確認できます。

## 設定と動作

### 長さと半径

初期値は長さ40m、直線、目標勾配0‰、縦曲線半径1000mです。長さは1〜512mで、画面には小数第1位まで表示します。マウスホイールでは長さを変更しません。

半径固定は常時有効で、Oによる切り替えはありません。半径10000mは直線として扱います。←でL側、→でR側へカーブを変え、反対側のキーでは半径を増やして直線へ戻します。直線で一度停止するため、キーを離して押し直すと反対側のカーブへ移ります。

長さ・半径は長押しに対応します。初期単位で40回変更すると、次から単位が10倍になります。長さは通常0.1→1m、Ctrl併用で10→100m、半径は通常1→10mです。Ctrl併用の半径は100m単位を維持します。キーを離す・方向を変える・Ctrlを切り替えると初期単位へ戻ります。

### スナップと接続

スナップは始点だけに適用し、生成される終点はスナップしません。距離モードでは自由始点の位置に加えて向きも角度スナップします。ブロックモードでは始点の位置をワールド基準の0.5m格子へ合わせます。始点高さの変更は自由始点の選択だけに適用し、既設端点と生成される終点を直接移動する操作ではありません。

別の理論レールと接続済みの端点は、始点のスナップ候補から除外します。

### 勾配と地上レール高合わせ

自由始点からは一定勾配、既設端点からは既存勾配から目標勾配へ変化する縦曲線を生成します。縦曲線半径の初期値・下限は1000mです。

既設端点を選び、目標勾配を0‰にしてUを押すと、既存勾配の直線区間を延長してから縦曲線で地上レール高へ合わせます。512m以内で成立する場合に長さを自動設定します。長さ・半径・勾配を変更すると、この設定を解除します。

### 画面表示

スナップ、L/Rと水平曲線半径、設定長、目標勾配、縦曲線半径を表示します。設定長は水平円弧と勾配から求める設計長です。円弧近似や既設端点からの縦曲線により、実際の3D長と差が生じます。

## 制限

使用前にワールドをバックアップしてください。単一の曲線で180度以上になる設定は生成できません。

- 通常ブロックは道床へ置換される場合があります。既設コアは保護し、安全な配置ができなければ生成を停止します。自動分割できない場合は通常レールでの生成を試し、通常レールの長さ上限は設定値（既定64m）です。

- Undoは直前の生成だけが対象で、縦曲線と直線に分かれた場合もまとめて撤去します。置換した通常ブロックは復元しません。ツール終了・スクリプト再読み込み・サーバー再起動後はUndoできません。
