# レール生成B（builder2）

半径・長さを事前に設定し、始点だけを選択してレールを生成します。KaizPatchX / AppleExtendedに対応します。

## 操作

- 初期値は長さ40m、直線、目標勾配0‰、縦曲線半径1000m。
- 右クリックで既設端点またはブロック上の始点を選択。自由点では選択時のプレイヤー方向を使い、既設端点ではその接線方向を使う。
- Enterで生成、左クリックで選択解除。Cは設定を維持して選択解除、Ctrl+Cは設定を初期化。Ctrl+Zで直前の生成を取り消し始点選択へ戻る。Hはヘルプ、Qは終了。
- PでOFF→距離→ブロックスナップ、Ctrl+Pで距離モードの角度を変更。始点だけに適用し、自由始点の方向は距離モードで角度スナップする。終点はスナップしない。
- 半径固定は常時有効でOによる切替はない。10000mは直線。←はL側、→はR側へ1mずつ変更し、Ctrlでは100m。反対側のキーは半径を増やして直線に戻し、さらに操作すると反対側のカーブへ移る。GUIは情報背景にL/Rと半径を表示する。
- ホイール上/下は長さを±1m、Ctrl+ホイールは±10m。Jは-0.1m、Kは+0.1m。長さは1〜2048m。
- ↑/↓は目標勾配を±1‰、Ctrl+↑/↓は縦曲線半径を±1000m。非接続では一定勾配、既設端点では既存勾配から目標勾配への縦曲線を使う。
- 設定長は水平円弧と勾配から求める設計長。ベジェによる円弧近似・既設端点からの縦曲線により実際の3D長には差が生じる。単一の曲線で180度以上となる設定は生成せず案内を出す。
- GUIはスナップ、L/R半径、設定長、目標勾配、縦曲線半径。
- TABホイールはA→B→分割→移動→複線→カント→分岐の順。

## 制限

生成とUndoの道床・コア保護、通常ブロックの置換、Undo履歴の寿命は[レール生成A](builder1.md)と同じです。使用前にワールドをバックアップしてください。

## 開発者向け実装情報

描画・サーバー処理は生成Aと共用し、生成・道床保護・既設端点再検証・Undoも同じ経路を使います。終点座標は`SRBXBuilderGeometry.plan`で計算し、サーバーでも設定から再計算します。両ツールは生成ログの接頭辞`[SuperRailBuilderX builder1]`を共用します。

B用のテクスチャを使用し、モデルは`builder1.mqo`を共用します。状態GUIの勾配と縦曲線半径には`gui_base.png`の(5,1)、(5,2)を使います。
