# レール生成A

始点と終点の2点からレールを生成します。自由点と既設レール端部を組み合わせて選択できます。

## 使い方

1. 始点を右クリックして選択します。
2. 終点を右クリックして選択します。
3. プレビューを確認してEnterで生成します。

レールアイテムを持っている場合は、そのモデルと設定を使います。持っていない場合は接続先レールの設定を使い、両端が既設レールなら始点側を優先します。両端とも自由点の場合はレールアイテムが必要です。

## 操作

| 操作            | 動作                                               |
| --------------- | -------------------------------------------------- |
| 右クリック      | 始点・終点を順に選択                               |
| Enter           | プレビューのレールを生成                           |
| 左クリック      | 最後の選択を1段階戻す                              |
| C               | 設定を維持して選択を解除                           |
| Ctrl+C          | 選択と設定を初期化。直前のUndo履歴は維持           |
| P               | スナップOFF→距離→ブロック                          |
| Ctrl+P          | 距離スナップの角度を1°→5°→15°へ変更。初期値5°      |
| O               | 曲線半径固定ON/OFF                                 |
| ← / →           | 半径を1mずつ変更                                   |
| Ctrl+← / Ctrl+→ | 半径を100mずつ変更                                 |
| ↑ / ↓           | 目標勾配を1‰ずつ変更                               |
| Ctrl+↑ / Ctrl+↓ | 縦曲線半径を1000mずつ変更                          |
| I / K           | 始点を選ぶ高さを±1/16m変更（自由始点の選択前のみ） |
| Ctrl+I / Ctrl+K | 始点を選ぶ高さを±1m変更                            |
| U               | 条件を満たす0‰の自由端を地上高へ合わせる           |
| Ctrl+Z          | 直前に生成したレールを撤去し、生成前の選択へ戻す   |
| H               | ヘルプを表示                                       |
| Tab長押し       | ツール切り替えホイールを開く                       |
| Q               | ツールを終了                                       |

矢印キーは長押しに対応します。固定半径は初期単位で40回変更すると10倍の単位へ加速し、それ以上は加速しません（通常1→10m、Ctrlは100m単位のまま）。チャットを開いてスクロールするとヘルプ全文を読めます。

## 設定と動作

### スナップと接続

スナップOFFは精密な自由点選択です。距離スナップでは自由始点を0.5m格子へ合わせ、自由終点を始点からの角度と0.5m刻みの距離へ合わせます。ブロックスナップはワールド座標の0.5m格子へ合わせ、角度や距離では丸めません。

自由点から自由点へ生成する場合、終点のXZはカーソル位置、高さは始点と目標勾配から決まります。初期値0‰では水平になります。ブロックスナップ中もこの場合のYは格子へ丸めず、目標勾配から求めます。

既設端部を選択すると、その位置と接線を引き継ぎます。分岐レールの端部にも接続できます。既設端部自体は移動しません。

別の理論レールと接続済みの端点はスナップ候補から除外します。同じ自動分割グループ内のコアは、別レールとして数えません。

### 曲線半径と縦曲線

- 未選択でOを押した場合は10000 m（直線）から開始する。
- 1点以上選択済みでOを押した場合は、現在プレビューしている曲線半径を整数mへ丸めて固定する。直線または半径を計算できない場合は10000 mとする。
- 1点選択中は、始点から視線先までの水平距離を弧長として、固定半径と始点接線から自由終点を計算する。カーソルが始点接線の左右どちらにあるかでカーブ方向を決める。
- 2点選択済みでOを押した場合は終点座標と現在の曲線形状を変更せず、固定値だけを今後の設定として変更する。
- レール生成後も半径固定ONと設定半径を維持し、OでOFFまたはCtrl+Cで完全リセットするまで連続利用できる。
- 半径固定中は視線先へ固定値を表示し、10000 mでは∞を表示する。

- ↑/↓で指定する勾配は自由端における最終目標値として扱う。
- Ctrl+↑/↓で指定する縦曲線半径は初期値1000 m、1000 m刻み、下限1000 mとする。設定値は生成後も維持し、Ctrl+Cで1000 mへ戻す。
- 既設端側の勾配から目標勾配までを指定半径で変化させ、残距離を目標勾配の直線として生成する。縦曲線区間と直線区間がある場合は2本の理論レールへ分かれる。
- Uによる0‰地上高合わせでは順序を逆にし、既設端の勾配を保つ直線区間の後に正円近似縦曲線を生成する。既設端の高さ・勾配、縦曲線の上下変位、地上目標高から必要な直線距離を求め、自由端の水平座標を現在方向へ延長する。現在の地上高で延長距離を作れない場合は1ブロック上、次に1ブロック下も試す。延長できない高さ関係や4096 m超は適用しない。
- 正円近似区間だけで選択端点へ到達し、利用できる距離では目標勾配まで変化できない場合は、到達可能な勾配までの正円近似レール1本だけを生成する。
- 例として20‰から0‰へ1000 m半径で遷移する場合、水平距離は約20 mで水平へ到達する。それより長ければ到達点で分割して残りを水平にし、短ければ0‰へ届かない正円近似区間だけにする。
- 縦曲線区間と直線区間へ分割されるプレビューでは、分割位置を表示する。
- 縦曲線と直線の2本を生成中に後半が失敗した場合は、先に生成した論理レールを撤去する。Ctrl+Zでも2本を1回分として逆順に撤去する。

### 画面表示

右上にスナップ、水平曲線半径、レール長、目標勾配、縦曲線半径を表示します。距離スナップ中は角度、ブロックスナップ中は「ブロック」を表示します。無限大の水平曲線半径は「直線」です。半径固定OFFでも選択中の曲線半径を表示し、レール長はプレビューの概算値です。

未確定点と選択点にはカーソル、マーカーブロック候補には方向マーカーを表示します。1点選択中はカーソルまで、2点選択後は生成予定の線形を表示します。

## 制限

使用前にワールドをバックアップしてください。

- 通常ブロックは道床へ置換される場合があります。既設コアは保護し、安全なコア配置ができなければ生成を停止します。自動分割ができない場合は通常レールでの生成を試し、長さ上限は設定値（既定64m）です。

- Undoは直前の生成だけが対象です。縦曲線が2本へ分かれた場合もまとめて撤去します。生成時に置換した通常ブロックは復元しません。ツール終了・スクリプト再読み込み・サーバー再起動後のUndoはできません。
