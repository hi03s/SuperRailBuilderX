# カント整形ツール 基本仕様・検証項目

## 操作

- `↑` / `↓`: 設計速度を1 km/hずつ変更する。初期値は100 km/h。長押しリピートに対応し、チャットには出さず`curvePanel`の数字で表示する。
- `Ctrl+←` / `Ctrl+→`: レール種類を切り替え、軌間と最大カントをチャット表示する。初期値は1067 mm。
- 右クリック: 通常レールの端点、`Cant Center`に対応する中央、端部・中央から線路長で10 m以上離れたレール上を複数選択または選択解除する。各選択点へ計算後のカント高さを`cantPanel`でmm表示する。
- 左クリック: 最後の選択を1段階戻す。
- `Enter`: 選択点のカントを一括適用する。
- `Ctrl+Z`: 直前の一括適用を取り消す。

端点または中央を選択すると、カント変更を受けるレールを水色で強調する。端部・中央から10 m以上離れた任意点では選択元レールを黄色で強調し、`Enter`時にその位置でレールを分割してから新しい共有端点へカントを適用する。同じ位置で別レール端点へ接続している場合は、接続相手へ反対符号のカントを同時適用する。任意点の分割とカント変更は1回の`Ctrl+Z`でまとめて元へ戻す。

均衡カント高さは `軌間(mm) × 速度(km/h)^2 ÷ (127 × 曲線半径(m))` とし、今回はカント不足を加えない。曲線半径は選択位置付近のRailMap接線変化から求める。共有端点ではカーソルが向いている側のレールを基準に曲率を選ぶ。直線は0 mmとする。高さからRTMの角度へはSRB3と同じ `asin(高さ / 軌間)` を使う。

| 種類                 | 最大カント |
| -------------------- | ---------: |
| 1067 mm              |     105 mm |
| 1372 mm              |     150 mm |
| 1435 mm (在来線)     |     150 mm |
| 1435 mm (新幹線)     |     200 mm |
| 1000 mm (モノレール) |     110 mm |

最大値はSRB3の実装を基準とし、1435 mm在来線だけを150 mmとして追加した。適用前にサーバー側で対象キー、端点座標、角度、在線状態を再検証する。KaizPatchX以外では安全に停止する。

## 実機確認

1. 初期表示が100、速度変更中にチャットが増えず、長押しで1 km/hずつ連続変更される。
2. レール種類が指定順で巡回し、1435 mmは`(在来線)`と`(新幹線)`を区別し、1435 mm・1000 mmを含む全種類の最大カントがチャットとヘルプへ表示される。最大値を超える計算結果は上限へ制限される。
3. 左右曲線・直線の始終端を選び、カント方向、mm表示、走行時の傾きが正しい。
4. 接続された2本の共有端点を1回選択し、両レールへ互いに反対符号の`cantEdge`が設定され、見た目と走行傾斜が連続する。
5. 曲線と直線の共有端点では、カーソルを曲線側へ向けると曲線側の半径とカントが選ばれ、直線側の0 mmに吸われない。
6. 中央選択で`cantCenter`が更新され、対象レールが水色で強調される。
7. 端部・中央から10 m以上離れた任意点を選ぶと対象レールが黄色になり、適用後は選択位置で2本へ分割されて共有端点のカントが連続する。`Ctrl+Z`でカントと分割の両方が元へ戻る。
8. 通常レールと自動分割レールの複数選択へ一括適用でき、`Ctrl+Z`で自動更新された接続相手を含む全対象が元へ戻る。
9. 在線中、変更済み、分岐レール、非対応ターゲットではワールドを変更せず失敗する。
