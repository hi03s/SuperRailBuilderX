# カント整形ツール 基本仕様・検証項目

## 操作

- `↑` / `↓`: 設計速度を1 km/hずつ変更する。初期値100 km/h、範囲0〜999 km/h。長押し対応。速度は状態GUIだけに表示し、カーソル先の数字パネルは廃止する。
- `Ctrl+↑` / `Ctrl+↓`: 設計速度を50 km/hずつ変更する。長押し対応。0 km/hでは選択レールの両端を水平にする。
- `Ctrl+←` / `Ctrl+→`: レール種類を切り替え、軌間と最大カントをチャット表示する。初期値は1067 mm。
- 右クリック: 通常・自動分割レールを論理RailMap単位で複数選択/解除する。同じレールのどこを指しても同じ選択になり、選択されたレールの両端へ計算後のカント高さを`cantPanel`でmm表示する。
- 左クリック: 最後の選択を1段階戻す。
- `Enter`: 選択レールの両端へカントを一括適用する。
- `Ctrl+Z`: 直前の一括適用を取り消す。

選択レールは水色、両端に接続して変更の影響を受ける未選択レールは黄緑色（99ff00）で強調する。ホバーしているレールは選択可能であることを示す黄色を優先し、同じ論理レールを重複描画しない。レール分割・中央だけの選択は廃止する。同じ端点位置へ接続するレールも向きに応じた符号で同時適用し、`Ctrl+Z`で接続相手を含む全変更を戻す。Undo失敗時は履歴を残して再試行できる。

均衡カント高さは `軌間(mm) × 速度(km/h)^2 ÷ (127 × 曲線半径(m))` とし、今回はカント不足を加えない。曲線半径は選択レールの各端付近のRailMap接線変化から個別に求める。直線と速度0は0 mm。曲線方向を独立して保持し、速度0から増速してもカントの符号を保つ。高さからRTMの角度へはSRB3と同じ `asin(高さ / 軌間)` を使う。

| 種類                 | 最大カント |
| -------------------- | ---------: |
| 1067 mm              |     105 mm |
| 1372 mm              |     150 mm |
| 1435 mm (在来線)     |     150 mm |
| 1435 mm (新幹線)     |     200 mm |
| 1000 mm (モノレール) |     110 mm |

最大値はSRB3の実装を基準とし、1435 mm在来線だけを150 mmとして追加した。サーバーは各レールの両端の組を検証し、旧分割/中央リクエストや重複/片端のみのリクエストを拒否する。互換層で対象キー、端点座標、角度、在線状態を再検証する。KaizPatch/AEに対応し、非対応ターゲットは安全に停止する。

## 実機確認

1. 初期速度100、通常上下は1 km/h、Ctrl上下は50 km/hずつ長押し変更され、GUIだけが更新される。0 km/hで両端が水平になり、増速で元のカント方向に戻る。
2. レール種類が指定順で巡回し、1435 mmは`(在来線)`と`(新幹線)`を区別し、1435 mm・1000 mmを含む全種類の最大カントがチャットとヘルプへ表示される。最大値を超える計算結果は上限へ制限される。
3. 左右曲線・直線をレール単位で選択し、両端のカント方向、mm表示、走行時の傾きが正しい。端点/中央/離れた位置から同じレールをクリックすると同じ選択を解除できる。
4. 選択レールの両端に接続するレールが黄緑色になり、接続端のカントと見た目が連続する。黄緑色のレールをホバーすると黄色が優先され、そこから追加選択できる。
5. 任意点で選択・適用してもレール本数/接続位置は変わらず、分割は発生しない。
6. 両端のカントパネルで透明部分が黒くならず、カーソル先に速度数字は出ない。
7. 通常・自動分割レールの複数選択へ一括適用でき、Ctrl+Zで接続相手を含め復元する。複数回のUndoと、失敗条件解消後の再試行も確認する。
8. 在線中、変更済み、分岐レール、非対応ターゲットではワールドを変更せず失敗する。
