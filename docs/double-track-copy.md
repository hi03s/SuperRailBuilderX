# 複線コピーツール

`SuperRailBuilderX_DoubleTrackCopy` は、既設の通常レールを論理RailMap単位で複数選択し、カーソルを伸ばした側へ指定間隔で複製する試験ツールです。分岐レールは選択対象外です。

## 操作

| 操作                       | 動作                                                             |
| -------------------------- | ---------------------------------------------------------------- |
| レールへカーソルを合わせる | 対象の論理RailMap全体を黄色で強調                                |
| 右クリック                 | 対象を選択。選択済みなら選択解除                                 |
| 左クリック                 | 最後の右クリック操作を1段階取り消す。選択解除の直後なら再選択    |
| `←` / `→`                  | 複製間隔を0.1 mずつ減少/増加。長押し対応。変更値をチャットへ表示 |
| `C`                        | 選択・選択履歴・向き・間隔を初期化。間隔は4.0 mへ戻る            |
| `Enter`                    | プレビュー中のレールを一括生成                                   |
| `Ctrl+Z`                   | 直前に一括生成したレールをUndo                                   |
| `H`                        | ヘルプ表示                                                       |
| `Q`                        | ツール終了                                                       |

間隔の下限は0.1 mです。生成成功後は選択と選択履歴だけを解除し、間隔を維持します。

## 複製範囲

最初に選択したレールの中点と接線を基準に、視線先がある側を複製方向とします。基準から視線先までの水平法線距離を `D`、間隔を `S` としたとき、複製列数は `floor(abs(D) / S)` です。各列は `S`、`2S`、`3S` … の位置に生成されます。

選択した全レールを各列へ複製します。理論長が2 m以下になった個別レールはプレビューにも生成要求にも含めません。

## 平行線形の計算

各RailMapの両端について、始端は始端接線、終端は終端接線を進行方向へ反転した接線を使い、その水平法線方向へ端点を移動します。Y座標は変更しません。

元の水平弦長を `L`、移動後の水平弦長を `L'` とし、始終端の水平・垂直アンカー長へ `L' / L` を掛けます。したがって元レールを単純平行移動するのではなく、同じ端点角度から新しいRailMapを構成します。カーブ内側は短く、外側は長くなり、アンカー長も曲率側に合わせて増減します。カント値は複製元から引き継ぎます。

## 接続

- 計算した端点から半径0.5 m以内に、選択中の複製元以外の接続可能な通常レール端点がある場合、その端点の座標・反転方向・反転角度を使用します。
- 同じ複製列内で選択レール同士の端点が一致する場合は、2本のRailPosition所有ブロックを`RailPosition.REVISION`に従う接続対として割り当てます。
- サーバーは生成直前に、複製元の論理レールキーと両端座標を再検証します。

## モデルの選択とUndo

- Enter時に大型レールアイテムを持っている場合は、そのRailPropertyを全生成レールへ適用します。
- 持っていない場合は、各複製元レールのRailPropertyを複製して使います。
- 生成RailPropertyは長距離でも安全に生成できるよう`autoSplit`を有効にします。
- 一括生成の途中で失敗した場合は、その要求内ですでに生成したレールを逆順にロールバックします。
- Undoは直前の一括生成記録を逆順に撤去します。複製元レールは変更しません。

実生成は現在KaizPatchXターゲット向けです。`mc1710`と`mc1122`では共通UIを生成できますが、既存builder1互換層と同様にワールド生成処理は安全に停止します。

## 実機確認項目

バックアップ済みワールドで次を確認してください。

1. 直線を1本選び、左右それぞれへ1列・複数列を生成する。
2. 連続する直線と曲線を順不同で複数選択し、複製後の共有端点を両方向に走行する。
3. 曲線の内側・外側で長さとアンカーが適切に変わり、元線形の単純移動になっていないことを確認する。
4. 勾配・縦曲線・カント付きレールで形状、接続、走行を確認する。
5. 0.5 m以内の既設端点へ吸着し、0.5 mを超える場合は自由点になることを確認する。
6. 内側複製で2 m以下になるレールがプレビュー・生成されないことを確認する。
7. 手持ちレールあり/なしで、指定モデル/複製元モデルが使われることを確認する。
8. 右クリックの選択・解除と左クリック履歴Undo、`C`初期化、間隔長押し、生成後の間隔維持を確認する。
9. `Ctrl+Z`で一括生成した全レールだけが撤去されることを確認する。
10. 分岐器、走行中レール、コア・道床衝突、途中失敗で安全に停止またはロールバックすることを確認する。

問題調査時は`[SuperRailBuilderX double-track-copy]`周辺のログと、選択順、間隔、複製方向、手持ちアイテム、接続先の状態を共有してください。
