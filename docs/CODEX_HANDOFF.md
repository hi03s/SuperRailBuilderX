## 次に行うこと

1. ローカル環境で `pnpm gen` と `pnpm build` を実行する。
2. ゲーム内で通常レール端点の探索、選択、移動先確定、Enter適用を確認する。
3. エラーや想定外の挙動があれば、ログと再現手順をこのファイルかGitHub Issueへ記録する。
4. 試験結果をもとに、スナップや接続成立判定の仕様を決める。
